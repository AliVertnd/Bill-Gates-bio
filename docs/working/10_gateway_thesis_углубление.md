## Gateway thesis restated (1 para)

Горно-Алтайск — не «город у склона» и не замена Манжероку/Чемалу, а **единственные воздушные и административные ворота Республики Алтай**: аэропорт (~0,5 млн пасс. сейчас → заявленная ёмкость >1,3 млн к ~2030), столица с судами/правительством/РКБ/вузом, городской сервисный контур и дешевле/ликвиднее жилой статус, чем апарт-полка у курорта. Покупают и снимают здесь не «отдых у подъёмника», а **снижение трения**: первая/последняя ночь, ранний вылет, командировки, медицина, кадры туротрасли, dual-use «себе + сдача», overflow когда курорт дорог/забит. «Талай» позиционируется как **urban Altai gateway base** (жить / приезжать / сдавать), а не ski-in продукт; цена 220–280 тыс. ₽/м² и 82,5% студий/1к логичны для Invest+Dual-use, не для массовой «семьи навсегда». Сила тезиса держится на **самостоятельной причине ночёвки в городе** (столица + сервисы); без неё gateway вырождается в транзит — как Минеральные Воды относительно Кисловодска/Пятигорска.

## Analogy matrix

| Аналог | Similarity к ГА | Difference | Lesson for Talay |
|---|---|---|---|

| **Петрозаводск → Карелия** | Столица + база выездов; обычные квартиры → гостевой фонд | Слабее winter-resort якорь | Важен сервис и УК, не «курортный фасад» |
| **Владикавказ → горы** | Столица + выезды | Другая геополитика/логистика | Городская идентичность важнее «просто аэропорта» |
| **Interlaken / Annecy** | Gateway lifestyle; second homes → cold beds → квоты на furnished tourist rentals | Зрелые альпийские рынки с жёсткой политикой | Риск бизнес-модели: регуляция cold beds; не строить P&L на вечной свободе STR |
| **Майма / Город Гор (локальный)** | Тот же gateway-коридор аэропорт↔тракт; dual-use жилой | Не столица; слабее РКБ/суды/вуз | Прямой жилой конкурент; «Талай» бьёт **городскими сервисами**, не «ближе к Манжероку» |

**Паттерн успеха gateway:** самостоятельная причина ночёвки + смешанный спрос + жилой статус + гибкий rental + честный P&L.  
**Паттерн провала:** чистый транзит / mono-STR / ценообразование как у подъёмника / cold beds без fallback.

## Positioning rules

### DO
1. **Gateway Base / Urban Altai Hub** — жить / приезжать / сдавать у ворот Алтая.  
2. Сравнивать с **Canmore / Innsbruck / Иркутск / городская полка ГА**, не с Красной Поляной ski-in.  
3. Якорить цену: «вход на уровне хороших городских ЖК и **в ~1,8–2,6× ниже** апарт-полки».  
4. Продавать **смешанный спрос** (тур + командировка + кадры + медицина + dual-use), не max ADR.  
5. Честный P&L: **net ~4–7%** base + капитализация инфраструктуры; Soft/Managed optional.  
6. Продуктовые крючки: remote check-in, хранение снаряжения, трансфер-логика аэропорт↔город↔Манжерок.  
7. Инфра-нарратив: аэропорт (ёмкость/статус) × тракт × мастер-план × газ × федеральные девелоперы — как **цикл капитализации**, не гарантия аренды.  
8. ЦА-деньги: **S/F Dual + Invest** первичны; L affluent — добор доверия.

### DON'T
1. Не называть «Талай» **квартирой на курорте / у склона / ski**.  
2. Не обещать **12–18%** и «как Сочи после Олимпиады».  
3. Не ценообразовывать как **Манжерок / Карлуу / Ризалта**.  
4. Не делать героем креатива **среднюю алтайскую семью** на 228–253 тыс. ₽/м².  
5. Не путать **пропускную способность 1,3 млн** с уже достигнутым трафиком.  
6. Не игнорировать **staff housing 2028** и **Амаду** в риск-блоке.  
7. Не продавать mono-STR без **long-term / corporate fallback** (Canmore/Bozeman/Annecy).  
8. Не строить бренд на «ГА = второй Манжерок» — это путь к антипримеру МинВод (транзит без причины остаться) **или** к Zakopane-hollow (курорт съедает город).

### Когда gateway thesis FAILS
1. **Потеря самостоятельной причины ночёвки:** гости/капитал едут сразу на курорт (трансфер стал слишком лёгким + отели/апарты закрыли first-night; город = МинВоды).  
2. **Mono-STR запрет / жёсткая регуляция** без готового long-term продукта.  
3. **Staff housing Манжерока + Амаду/Катунский промузел** снимают дефицит аренды и dual-use scarcity → ADR/occupancy и перепродажа падают.  
4. **Прайс как курорт** при городском ADR → распроданность как у рынка −47,8% г/г.  
5. **Аэропорт/тракт срывают сроки** → инфраввейт в цене не окупается.  
6. **Турпоток стагнирует**, зима Манжерока не масштабируется → город теряет spillover.  
7. **Путаница юрлица/бренда СД** убивает доверие межрегиона (S/F Dual).
