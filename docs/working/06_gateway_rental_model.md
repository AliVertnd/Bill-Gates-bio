## Hard vs assumption

| Hard | Assumption |
|---|---|
| Asking ADR Sutochno/Avito/Ostrovok ГА: часто 4,2–5к, витрина от 2,5к до ~7к | Achieved ADR = asking |
| Майма: часто 3–4к, качественные до 5–7к | Occupancy 35/45–55/60% |
| Манжерок/Чемал: выше (5–12к+) | УК 20–25%, коммуналка 8–12к/мес, налог 6% с gross |
| Long-term ГА: часто 32–60к+ /мес | Без capex мебели/простоя |

## Вердикт для инвестора

Gateway-тезис **защитим на чеке 7,5–10,5 млн** при честной коммуникации base **~4–9% net** (не 15–18%).  
На **450к+/м²** апартах та же городская экономика **не работает** — нужен курортный ADR/оператор.  
Сила «Талая»: жилой статус + ниже вход + long-term/corporate fallback (кадры, РКБ, командировки).
