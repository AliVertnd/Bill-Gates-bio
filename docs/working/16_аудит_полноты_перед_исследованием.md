# Аудит полноты данных перед научным исследованием

**Дата:** 05.08.2026  
**Вопрос:** взяли ли мы «всё» по АН (~100), конкурентам (12–20), логике города, коммерческим помещениям?

## Вердикт одной строкой

**Нет — не «всё». Для сильного исследования рынка базы хватает, но по четырём блокам есть разные уровни глубины.** Ниже — честно по полочкам.

## 1. Агентства недвижимости

| Что ожидали | Что есть в материалах | Оценка |
|---|---|---|
| «Около сотни» АН/риэлторов | Shortlist ~10 названий + пометка «~29 в каталогах» | **Неполный срез** |
| Условия работы, комиссии | Логика пилота 2–3 АН; шкала комиссий из меморандума (к утверждению) | **Средне** |
| Фильтр качества | РГР: **2** сертифицированных АН, **7** аттестованных специалистов во всей РА | **Сильный факт** |

**Что показали открытые источники (август 2026):**
- Каталог mirstat по ГА: **29 из 29** карточек — но в списке шум: гостевые дома, «АвтоЮрист», организации не из первички.
- РГР: только **Гравитон** и **АН «Республика»**.
- 2ГИС: рубрика «агентства / риэлторские услуги» — много ИП и мелких точек; **полной выгрузки «~100» у нас нет**.

**Вывод:** «около сотни» как оценка фрагментированного рынка (фирмы + ИП + частники агломерации) **правдоподобна как порядок величины**, но **не как наш поимённый реестр**. Для исследования корректно писать: *в каталогах города фиксируется порядка трёх десятков организаций с вывеской «недвижимость»; сертифицированных РГР — две; рабочий канал первички — узкий shortlist; полный контур частных посредников требует отдельной инвентаризации 2ГИС/ЕГРЮЛ*.

**Добор до исследования:** расширенная таблица ~20–25 очищенных названий из каталога + явная оговорка про лимит.

## 3. Логика развития города («постройка» / инфраструктурный цикл)

| Тема | Статус |
|---|---|
| Тезис «ворота, не курорт» | Сильный, с аналогами и антипримером |
| Аэропорт, Чуйский тракт, мастер-план ~2026, газ, КРТ Амаду, Катунский промузел, стратегия населения до 89,2 тыс. | Есть как **инвест-досье**, не как полный градостроительный том |

**Вывод:** для главы «город как система» базы достаточно при честных границах. Это не генплан-исследование.

## 6. Решение для исследования

1. В тексте **не** писать «мы изучили все ~100 агентств» — писать методику: каталоги → очистка → РГР → shortlist первички.  
2. Конкурентов подать как **12 проектов мониторинга + расширение до 15–16 с внеагломерационными**.  
3. ПОН и частный риэлторский «хвост» — в разделе ограничений и приложений.  
4. Научный том строить на том, что **проверено**; пробелы не маскировать.
