## 1. Макро-тренды спроса (контент = зеркало спроса)

|---|---|---|
| Турпоток РА **2,8 млн** (2025), +~5% план 2026 | Власти / Толк | Рынок гостей растёт, но это **не** автоматом спрос на лоты 9–11 млн |

| Спрос на **авторские / гастро / digital-detox / фототуры**, не только «лежать» | Толк | Контент «жизнь у ворот» + выезды, не «апарт у подъёмника» |

| Сравнение с ранней Красной Поляной / Шерегешем | эксперты 2026 | Инвест-нарратив «ранний вход в цикл» — осторожно, с инфраструктурными фактами |

## 3. Контент-матрица под сегменты

| Сегмент | Хук в соцсетях | Запрещено |
|---|---|---|
| **Invest** | Инфраструктурный цикл (аэропорт 1,3M, тракт, мастер-план); сценарии аренды **диапазоном** | «15–18% гарантия», сравнение 1:1 с Карлуу |
| **Dual-use** | «Своя база + сдача простоев»; первая/последняя ночь; ранний вылет; сервисы города | «Шале у подъёмника» |
| **Local affluent** | Качество дома, двор, статус, сертификаты/вторичка как капитал | «Для средней зарплаты» |
| **Travel awareness** | UGC гор → мягкий CTA «где жить в городе-воротах» | Подмена ЖК курортом |

## 4. Практический план соцконтура (M0–M2)

1. **Слушание (2 недели):** выгрузки комментариев Манжерок TG/VK + паблики недвижимости ГА → словарь возражений.  
2. **Свои каналы Талай:** VK + Telegram (минимум); тон — городской, спокойный, без курортного шума.  
3. **Посевы:** 3–5 travel TG (не Манжерок как «мы часть курорта», а «логистика ворот»).  
4. **Партнёрский контент АН:** единые карточки лотов, сторис-скрипты.  
5. **Антикризис:** заранее ответы на «дорого / не продаётся / апарт обман».

## 5. Метрики
- ER и стоимость подписчика — вторично.  
- Главное: **лиды с UTM** → квалифицированные → брони.  
- Отдельно: доля негатива про «доходность» в комментариях (риск-индикатор).
