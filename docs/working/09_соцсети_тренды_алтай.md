# Соцсети и тренды Алтая → следствия для «Талай»

**Версия 2.0 · 28.07.2026**  
Углубление: платформы, аудитории Манжерока, тренды 2025–2026, Сибирь vs федерал, матрица сегментов, гипотезы H-M, риски галлюцинаций.  
Источники: открытые TG/VK/MAX-карточки, Толк, ТАСС/Интерфакс, РБК, Profi.Travel, Morein, пресс-релизы Манжерока/Сбера. Не замена медиааналитики с кабинетами.

**Канон позиционирования:** urban gateway apartments в Горно-Алтайске — **не** ski-resort framing, **не** «жить у подъёмника».

### Манжерок: размер аудитории vs размер спроса

| Метрика | Цифра | Интерпретация |
|---|---|---|
| Гости курорта **2025** (год) | **~1 млн** (+~30% г/г, заявления курорта/Сбера) | Контент-аудитория VK/TG **меньше** физического потока — подписчики ≠ гости |
| Зима **2025/26** | **~530k** гостей (+10%) | Зима = федеральный ski-драйвер; spillover в ГА возможен, но ADR/ожидания «курортные» |
| Гео курорта (заявления менеджмента) | **МСК/МО и СПб** в топе, Сибирь (Нск, АК, Ирк, Крск) в тройке | На курорте федерал **сильнее**, чем в среднем по РА (~70% Сибирь авто) |
| TG ER (порядок) | ~4k views / 52k sub ≈ **~8%** view-rate | Нормально для бренда; не «мёртвая» накрутка на глаз, но без TGStat paid — осторожно |

### Сибирь vs федерал — разные медиа-слои

| Слой | Кто | Как доезжает | Где живёт в соцсетях | Что работает в сообщении |
|---|---|---|---|---|
| **Сибирь (ядро РА)** | ~**70%** гостей РА; авто + автобус | Чуйский тракт, Нск/Барнаул/Кемерово | VK локальные + travel TG 1–10k + автотуры MAX-BUS / туроператоры | **Логистика без пафоса:** парковка, выезд на тракт утром, «своя база между поездками», чек ниже апартов, знакомый городской сервис |
| **Федерал (растущий слой)** | МСК/СПб/север + авиа | Аэропорт ГА (14+ направлений летом 2026: +Ирк, Оренбург, Сургут, Чита) | Манжерок VK/TG, федеральные travel, YouTube, инвест-медиа (Morein, BARNES, РБК) | **Снижение трения рейса:** первая/последняя ночь, ранний вылет, «не спать в палатке у терминала», dual-use + честный P&L vs Карлуу/апарты |
| **Инвест-контент** | Покупатели земли/апартов | Не обязательно туристы | `@denginaaltae`, `@altai_04`, YouTube-обзоры ЖК | Инфраструктурный цикл (аэропорт 1,3M, тракт, мастер-план); **запрет** «гарантия 12–18%» |

**Вывод по платформам:** Манжерок даёт **awareness Алтая**, но конвертит в «курортный продукт». Талай покупает у Манжерока только **внимание к региону**, а продаёт **городские ворота** — отдельные креативы и отдельные посевы (travel TG + локал VK + инвест-ниша), не ретаргет «хочу шале».

## Content trends that HELP Talay

Тренды спроса 2025–2026 (Толк / туроператоры Wow Way, «Большой Алтай», «Плот»; власти РА; АТОР-сигналы), которые усиливают **gateway / dual-use / urban base**:

1. **Автотуризм как норма** (~60% личные авто, **>70%** с экскурсионным; программа автотуризма до 2035)  
   → Контент: «вечером в городе — утром на тракт»; паркинг, зарядка маршрута, bypass Манжерока без жизни на курорте.

2. **Авторские / кастомные туры + «на старте и финише — комфорт»** (Липовик: 5★ на входе/выходе + дикая середина)  
   → Талай = **комфортный bookend** экспедиции, не замена Укоку.

3. **Digital-detox в глубине + связь в населённых пунктах**  
   → Город = связь, аптека, РКБ, продукты; горы = detox. Не продавать «детокс в студии».

4. **Гастро / локальная кухня / микс актив + SPA**  
   → Городские рестораны ГА + выезд; не ski-dining Манжерока как identity ЖК.

5. **Круглогодичность и рост зимы** (Манжерок 530k зимой; санатории; события Эл Ойын / Ойна Фест в ГА)  
   → «База на весь год», midweek командировки, события столицы.

6. **Легализация размещения** (реестр КСР: с ~168 на нач. 2025 → **>1,5k** объектов)  
   → Коммуникация: жилой статус + понятные правила сдачи / УК-опция важнее «серой посутки».

7. **Авиадоступность федералов** (пассажиропоток аэропорта >500k в 2025; H1’26 +15,8%; цель терминала >1,3M)  
   → Shorts/Reels: «рейс → 20 мин → своя квартира → завтра Чемал/Манжерок/Телецкое».

8. **Скепсис к курортной «резервации»** у опытных traveller’ов  
   → Позиция «город, а не курортный Disneyland» совпадает с трендом аутентичности — если не копировать курортный визуал.

9. **Инвест-нарратив «Алтай = ранний цикл»** в СМИ (с оговорками)  
   → Работает только с **фактами инфраструктуры** и честным net 4–9%, не с ROI-мемами апартов.

10. **Short-form edutainment** (маршруты, чек-листы, «как не слить бюджет на Алтае»)  
    → Образовательный контент gateway > красивые горы без CTA.

### Сибирь vs федерал — тональность

| | **Сибирь** | **Федерал** |
|---|---|---|
| Тон | Прямой, без «открытия Сибири»; уважение к тому, что Алтай уже «свой» | Объясняющий: логистика рейса, климат, что такое ГА vs Манжерок |
| Доказательства | Километраж, время до Чемала/Телецкого, цены знакомых баз | Пассажиропоток аэропорта, прямые рейсы, сравнение с Сочи/КП **осторожно** |
| Возражения | «Дорого для ГА / лучше Майма» | «Зачем не на курорте / апарт с оператором» |
| Ответ | Городские сервисы + жилой статус + чек | Dual-use + ниже вход + не mono-STR |

## Hallucination risks (fake subscriber counts etc.)

| Риск | Что видели в открытых данных | Правило для Талая / IMPRO |
|---|---|---|
| **Расхождение каталогов TG** | `@rusaltai` 1,8–2,5k; `@na_altai` 2k vs 4,8k в разных агрегаторах; `@altai_04` 4,6 vs 5,1k | **Канон = скрин t.me / TGStat на дату посева**, не цифра из статьи |
| **VK «~170k Манжерок»** | 169k (Remarka) vs 173–174k (VK Video) | Диапазон ок; не писать «200k+» |
| **Подписчики ≠ покупатели** | 52k TG / 170k VK << 1M гостей курорта и << платёжеспособных на 9–11 млн | KPI = UTM→qual→бронь, не ER канала |
| **Накрутки и мёртвые чаты** | Мелкие «недвижимость ГА» чаты 20–30 чел.; объявленческие паблики | Не покупать «охват» в чатах <2k без теста ER |
| **Смешение РА и Алтайского края** | Толк: «>5 млн» = край+республика; РА отдельно **2,8 млн (2025)** | В текстах Талая только РА + ГА, иначе завышенный рынок |
| **«70% Сибирь» vs «70% авто»** | Филипенкова: авто/экскурсии >70%; отдельно ~70% из СФО | Не сливать в одну фразу без источника |
| **Прогнозы доходности апартов 12%+ / +80% к 2030** | Рекламные материалы девелоперов/брокеров | **Не переносить** в Талай; только свой коридор из `06_gateway_rental_model` |
| **Пассажиропоток «до 2 млн»** | Заявки Карлуу/маркетинг vs официальный ориентир терминала **>1,3 млн** | В контенте — консервативная официальная цифра |
| **Instagram-метрики «как было»** | Исторический драйвер фототуров; сейчас недоступен для легального performance | Не обещать «вернём охват IG» |
| **AI-генерация «секретных» локаций и фейковых отзывов** | Риск в travel UGC 2025–26 | Только реальные съёмки ГА/тракта; маркировка рекламы |

6. **Метрики:** лиды UTM → qual → бронь; доля негатива про доходность; H-M1…H-M3 как обязательные тесты M1.
