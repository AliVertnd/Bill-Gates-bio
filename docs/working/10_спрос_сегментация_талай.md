**Банковский порог** обычно DTI ≤40–50% → для рыночной ипотеки на 9,44 млн нужен доход **~220–275 тыс.** (один заёмщик) или эквивалент капитала + созаём. Это **совпадает с мемо-профилем «жить 120–400» только в верхней половине**, не со средней ЗП 75–86.

### Stress-test долей меморандума (~35% live / 25% family / 20% dual / 20% invest)

| Доля мемо | Что ломает | Вердикт |
|---|---|---|
| **~35% «жить самостоятельно»** | Средняя ЗП не тянет; сам мемо требует 120–400к; ПВ 2,2–2,8 млн без вторички/сертификата — 7–14 лет; Шония: уже 30–35% покупателей non-local | **Завышена как массовый локал.** Реалистично: **20–28%** сделок = affluent live (вторичка, сертификат 15–18 млн, бизнес, returnees, remote) — **не** «средняя алтайская семья» |
| **~25% «жить семьёй»** | В старте только **17,5%** лотов 2–3к (55/314); семейная ипотека режет чек >6 млн; DTI на 2к убийственный без капитала | **Продуктово и платёжеспособно завышена для Q1.** Рабочий коридор пресейла: **8–15%** сделок / выше доля выручки на лот |
| **~20% dual** | Чек 9–11 млн + турпоток 2,8 млн + «точка возврата» (Шония) + Князев (second home) — **недооценена** относительно платежеспособности | **Поднять до 30–40%** намерений в стартовой выручке |
| **~20% invest** | 82,5% компактных лотов; вход ниже апартов в 1,8–2,6×; yield base ~4–9% net (`06`) | **Поднять до 25–35%** единиц; в выручке чуть меньше из‑за меньшего чека |

**Ключевой разрыв мемо:** доли сценариев смешаны с «ядро пресейла = локал» (28/54 брони = 52%). Локал может дать **скорость и доверие**, но на полке 220–280 **не равен** 60% «жить» по намерению. Non-local у Селфстроит уже 30–35% — и это **до** сильного dual/invest нарратива «Талая».

## Recommended priority for GTM (не равно долям мемо)

**Порядок приоритета пресейла сен–дек 2026 (выручка + скорость к 300 млн):**

1. **S-Dual** — НСК/Барнаул/Кемерово: вторая квартира / точка возврата / «приезжать + сдавать»  
2. **S-Invest + F-Invest** — компактный пул; оферта Soft/Managed; только диапазоны yield  
3. **F-Dual** — точечно через брокеров/One Company после оферты УК  
4. **L-Live-A** — сертификаты, продажа вторички, предприниматели, квартира детям; **не** креатив «доступно на средней ЗП»  
5. **L-Family** — дефицитные 2–3к, длинный цикл; не раздувать медиапод них  
6. **L-Dual / corporate** — opportunistic

**Медиамикс (рабочий, до утверждения бюджета):** ~**40% Siberia** / ~**30% Federal+Invest** / ~**30% Local** (офлайн+АН+сертификаты = скорость первых 25 броней).

**Почему не копировать 35/25/20/20 в медиа:**  
- 60% «жить» конфликтует с 82,5% компактных лотов и affordability;  
- 25% семья конфликтует с 17,5% семейных лотов;  
- KPI 300 млн ≈ 30×~10 млн достигается быстрее на Dual/Invest с готовым капиталом, чем на накоплении ПВ локалом 7–14 лет.

## Messaging implications per segment

| Сегмент | Говорить | Не говорить | Proof points |
|---|---|---|---|
| **S/F-Dual** | «Своя база на Алтае: приезжаете — ваше; нет вас — опциональное управление» | «Гарантированный доход»; «апарт-отель» | жилой статус; блок дат; срок стройки; кто УК |
| **S/F-Invest** | «Вход 7,5–10 млн vs 450+ тыс./м² апарты; base net ~4–9%; long-term fallback» | «15–18%»; «как депозит» | калькулятор 3 сценария; юрстатус; ликвидность перепродажи |
| **L-Live-A** | «Современный городской дом: двор, паркинг, без частного сектора; ранняя цена» | «Доступно каждой семье»; сравнение только с Маймой по «дешевле» | пресейл 228; инфраструктура; сертификат/рассрочка как инструмент |
| **L-Family** | «Редкие 2–3к + кладовая/паркинг; держим под вас» | Массовый семейный креатив на всю экспозицию | дефицит лотов; школа/двор (честно про 2 смену) |
| **S-Live / remote** | «Город-ворота + интернет + сервисы в доме» | Курортная романтика юрты | аэропорт, газ, коворкинг/сервисы (если факт) |
| **Returnee** | «Точка возврата без отельной премии» | Туристический yield-first | кейсы Шония-типа; НСК-бренд СД |

**Anti-messages (единый запрет для креатива и АН):**

1. «Гарантированная доходность / 15%+ / как вклад»  
2. «Доступное жильё для средней алтайской зарплаты»  
3. «Апарт-отель / отельный сервис включён в ДДУ»  
4. «Семейный квартал» как главный оффер при 82,5% студий+1к  
5. «Алтай всегда дорожает — покупайте любой лот» (после −47,8% распроданности)  
6. Путаница бренда с ООО «СКД» ГА без сверки ИНН СЗ  
7. Lock-in УК («только наша управляющая»)  
8. Сравнение с Маймой только по цене м² без статуса/сервиса

## Что пересчитают первые 25 броней

Минимальный **CRM-срез на каждую платную бронь** (иначе доли мемо некалибруемы):

| Поле | Зачем |
|---|---|

| Geo прописки + geo денег (откуда ПВ) | H-S4–5, H-S9 |
| Доход домохозяйства (интервал) / источник ПВ (зарплата / вторичка / сертификат / бизнес / иное) | H-S2, affordability |
| Лот: формат, этаж, вид, терраса | product-fit |
| Пакет: white / Soft / Managed | H-S6 |
| Оплата: 100% / рассрочка / ипотека (семейная / рыночная / mixed) | H-S8 |
| Lost reason если не ДДУ | H-S7 |
| Канал: АН / digital L|S|F / брокер МСК | CAC и медиамикс |
| «Returnee?» (да/нет) | H-S9 |
| Сравнение с какими проектами (Майма / Город Гор / апарты / Амаду) | positioning |

**Правила перекалибровки после N=25:**

- Если Live+Family >50% единиц → усилить локал и семейные лоты; не резать Local бюджет.  
- Если Dual+Invest >60% → сдвинуть медиа к Siberia/Federal; ускорить УК и калькулятор.  
- Если Family demand > supply 2–3к → waitlist + удержание видовых; не обещать массово.  
- Если Invest отваливается на yield → проверить, не утекают ли «15%» скрипты АН.  
- Если L-брони есть, а DDU нет → проблема не спроса, а ипотеки/ПВ/доверия к срокам.  
- Средний чек и доля Managed обновить в прогноз 300 млн (модель: N×чек×конверсия 60%).

## Hallucination risks

1. **Доли 35/25/20/20** — из концепции продвижения, меморандум сам маркирует как гипотезы; нельзя цитировать как market fact.  
2. **«Платёж ~52к»** без ставки — смешивает family mortgage и рынок; на 20% средний чек ≈ **110к**.  
3. **«Локал = ядро пресейла»** ≠ «локал = главный объём выручки на 220–280».  
4. **КСР Майма растёт, КСР ГА плоский** — нельзя экстраполировать курортный ADR на городскую посутку 1:1.  
5. **Non-local 30–35%** — факт Селфстроит, не «Талая»; перенос только как бенчмарк направления.  
6. **Yield 4–9%** — модель с допущениями occupancy/ADR (`06`), не audited P&L.  
7. **GPT-брифы PRO/FAMILY/RESIDENT** — не канон; риск подменить JTBD lifestyle-лейблами.  
8. **Росстат первичка Q1’26 скачок** — возможна смена выборки; не доказывать «рынок = 276».  
9. **Демографический спрос** — населения нет; любой тезис «город растёт → купят» ложен.  
10. **Corporate/staff housing Манжерока** — драйвер аренды, не автоматически DDU пресейла.
