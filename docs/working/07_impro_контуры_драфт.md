# IMPRO × СД — контуры 600–900к/мес (v2.0 · канон из zip)

**Статус:** привязано к `docs/sources/impro_group/` (ветка `research-agency-docs-framework-5433`, zip 28.07.2026).  
**Текущий контракт СД:** ~**200к/мес** = SEO + часы разработки (слой L1, не L2-контур).  
**Цель:** ретейнер **L2 «маркетингово–IT-контур»** под запуск «Талай» (продажи с 1.09.2026, KPI ≥300 млн ДДУ).

---

## 1. Канон IMPRO (что продаём на самом деле)

Не performance-агентство и не «ещё SEO». Категория:

> **Встроенный партнёр по маркетингово–IT-контуру роста** — одна точка ответственности: выбор направления → внедрение → подрядчики.

Источники: `01-kompaniya/kto-my.md`, `edinaya-poziciya-blok-01.md`, `08-uslugi-i-produkty/katalog-uslug-chernovik.md`.

| Параметр IMPRO | Значение |
|---|---|
| ICP | Средний бизнес ~**5–10 млн ₽/мес** выручки |
| Ядро выручки | Ретейнер контура **~600 000 ₽/мес** |
| Мин. платный шаг | **≥80 000 ₽** (воркshop/диагностика от **140–250к**) |
| Средний чек | ~500 000 ₽ |
| LTV ретейнера | ~**25 млн ₽** за 3–5 лет |
| Медиабюджет | **Всегда отдельной строкой** |

### Пять блоков функционала (ваш офер = L2-состав)

1. **Управление развитием** — анализ, узкие места, приоритеты, roadmap, контроль  
2. **Архитектура решений** — сайт, CRM, аналитика, подрядчики, технологии  
3. **Исследования** — практики, инструменты, AI → что внедрять **именно здесь**  
4. **Аналитика** — маркетинг, сайт, CRM, BI, прогнозы  
5. **Реализация** — внедрение, координация, приёмка (не «советы в стол»)

### Вход в контур (воронка IMPRO)

```text
Discovery (бесплатно, fit/no-fit)
  → Диагностический воркshop / Growth-аудит девелопера (140–300к)
  → Зачёт в 1-й месяц ретейнера при входе за 30–45 дней
  → L2 Ретейнер контура от 600к/мес
```

Для СД: стратегия контура «Талай» частично уже собрана в этом workspace → воркshop можно **сжать/зачесть** в апгрейд с 200к.

## 2. Формула цены (из model-ceny-i-koefficienty.md)

```text
Цена оффера =
  Σ (база микроуслуги × k_формат)
  × K_клиента
  × K_срочность
  + PMO-наценка контура
  + медиабюджет / лицензии (отдельно)
```

**K_клиента для Сибирь Девелопмент × «Талай» (рабочая оценка):**

| Ось | К | Обоснование |
|---|---:|---|
| `K_otrasl` | **1.2** | Девелопмент / сложные продажи |
| `K_masshtab` | **1.0–1.2** | 1 новый ЖК, но KPI 300 млн и 641 лот |
| `K_zrelost` | **1.0** | SEO/сайт/Bitrix уже есть год+ |
| `K_stakeholder` | **1.2** | MD + основатель |
| `K_podryad` | **1.2** | АН, УК, Russ OOH, local SMM под PMO |
| `K_srochnost` | **1.0–1.25** | Старт 1.09 → при сжатии авг–сен |

База ядра IMPRO **600к** × типичный K для девелопера **~1.35–1.55** → коридор **~810–930к**.  
Практически упаковываем в **600 / 750 / 850–900** (нижняя граница — лояльность + SEO/dev уже внутри; верхняя — полный launch PMO).

## 3. Пакеты для встречи с MD

| Пакет | ₽/мес | Состав L2 (язык клиента) |
|---|---:|---|
| **Contour Base** | **600–650** | 5 блоков в базовой ёмкости + SEO/dev (наследие 200к) + weekly status + PMO 1–2 подрядчика |
| **Contour Launch** | **~750** | Base + **Growth office «Талай»**: упаковка Invest/Dual, partner playbook АН, performance office, sales enablement ОП (~5), BI/DDU-forecast lite |
| **Contour Control** | **850–900** | Launch + полный PMO подрядчиков (АН/УК/медиа), call QA/AI, риск-контроль формулировок доходности, forecast к 300 млн |

**Не входит ни в один пакет:** медиабюджет; комиссии АН; оснащение квартир под УК; штат ОП СД.

## 5. Как говорить на встрече (из kto-my.md)

> Сейчас мы закрываем SEO и разработку — это один слой.  
> Для запуска «Талай» нужен **контур**: стратегия, маркетинг, IT, подрядчики и аналитика в одной ответственности.  
> Не обещаем 15% доходности — обещаем систему, в которой видно, куда расти и что внедрять, и доводим до результата внутри вашей команды.

**Анти-позиция:** «Мы не агентство на лиды. Мы — контур внутри.»
