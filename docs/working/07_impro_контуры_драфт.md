# IMPRO × СД — контуры 600–900к/мес (v1.1)

**Статус:** рабочая офер-рамка по словам IMPRO (функционал + вход «стратегия развития маркетингового и цифрового контура»).  
Zip модели агентства — ожидается. Текущий ретейнер **~200к = SEO + часы разработки**.

---

## 1. Сдвиг роли

| Сейчас | Цель |
|---|---|
| Исполнитель SEO/разработки | **Функция управления развитием** маркетингового и цифрового контура ЖК |
| Точечные задачи | Координация маркетинга + IT + подрядчиков + исследований + аналитики + roadmap |

Продаём не «больше услуг», а **взятие на себя функции**: анализ → узкие места → приоритеты → дорожная карта → контроль → внедрение.

## 4. Деньги: от 200к к 600–900к

**База 200к** остаётся внутри (SEO + dev hours), но перестаёт быть «всем контрактом».

| Пакет | ₽/мес | Смысл |
|---|---:|---|
| Growth Base | 600–650 | 5 блоков в базовой ёмкости + SEO/dev + PM |
| Growth Launch | ~750 | + усиление упаковки Invest/Dual, sales enablement, контент, подрядчики |
| Growth Control | 850–900 | + полный DDU-forecast, call QA, риск формулировок, контроль медиа/АН |

Медиабюджет — **сверх** ретейнера (подтвердить на встрече).

### Ориентир модулей (сумма в 620–900)
1. SEO+dev (наследство 200к) — 180–220  
2. Управление развитием + PM — 80–120  
3. Архитектура / подрядчики / CRM — 70–110  
4. Исследования + лучшие практики — 50–80  
5. Аналитика / BI / forecast — 70–110  
6. Реализация performance + упаковка — 120–180  
7. Репутация / риск формулировок — 40–70
