## Competitive window for Talay · Sept–Dec 2026

| Фактор | Implication |
|---|---|
| **Пресейл сен–окт** при медиане ГА ~227 и компсах 178–250 | 228 = **market entry**, не демпинг; 253 на старте = премия → нужна УК/стройка/дефицит. |
| **Олимп** выдаёт ключи до **конца 2026** | Уводит «хочу жить/сдавать сразу» и статус-центр; «Талай» не выигрывает сроком — выигрывает **чек + optional management + жилой пакет**. |
| **Город Гор** уже в рынке, длинный горизонт 2027–29/35 | Главный dual-use конкурент весь период; дифференциация: **город ГА vs Майма-КРТ**, доказанный оператор vs «В Горах» без track record. |
| **Амаду старт ~3кв2026** | Окно **сен–ноя**: закрепить брони/первые ДДУ и брокерский канал **до** федеральной шумихи Брусники; дек — риск перетягивания внимания. |
| **Домклик −47,8% распроданности** | Рынок **не** « Absorbs всё»; KPI 300 млн (~29–32 ДДУ) реалистичен только с плотной воронкой, не с «Алтай дорожает сам». |
| **Карлуу / апарт-полка** | Не бьёт по цене м²; бьёт по **yield-обещаниям** в голове инвестора → «Талай» обязан давать **честный P&L 4–7% net**, не соревноваться в 13–20%. |
| **Сезонный турпик** (осень→зима Манжерок) | Хороший фон для dual-use story; плохой — если обещать загрузку как у отеля 70%. |

**Сжатый вывод окна:** Sept–Oct = **capture** (бронь 100к, narrative vs Майма и апарты). Nov–Dec = **defend** против Амаду + готового Олимпа + шума Город Гор. Без названного оператора/оферты УК окно сжимается.

## Claims to NEVER copy from competitors

1. **Гарантированная / «пассивная» доходность 13–20%+** или «от 2 / 2,7 млн ₽/год» (Ризалта, Карлуу marketing max, отдельные апарт-лендинги).  
2. **Окупаемость 7 лет** на краткосрочке без раскрытия ADR, загрузки, комиссии УК, сезонности (Город Гор / CREDO PR).  
3. **«Аренда в РА = 1500 ₽/м²»** как универсальный якорь доходности без сегмента, локации и long vs short (Чуйские кварталы / Bankfax).  
4. **Прогноз капитализации ×2,7 к 2035** (CORE.XP → Город Гор) как обещание покупателю.  
5. **Подмена бренда и юрлица** без прозрачности (Селфстроит ↔ САНУР / Горный гектар / Метр / ВиноГрад) — у «Талая» риск путаницы с локальными СЗ; не усиливать.  
6. **«Лидер рынка / #1»** на базе ERZ quality score или PR (Дом 1824) без ДДУ.  
7. **Отель-оператор без договора** или внутренняя УК, поданная как Cosmos/Zont-класс («В Горах»).  
8. **Resort framing для городской квартиры** («курорт у вас дома») без честного юрстатуса и правил посутки.  
9. **Lock-in УК / MGP** в стиле leaseback без права личного использования на понятных условиях.  
10. **«Алтай всегда дорожает»** на фоне Домклик −47,8% распроданности и снижения цен г/г в РА.

| Риск | Почему | Как не ошибиться |
|---|---|---|
| **Оферты = продажи** | 66/149/63 «в продаже» ≠ остаток / sell-through | Всегда писать «экспозиция»; ДДУ — отдельный контур |
| **Путаница застройщиков Селфстроит** | Один бренд, разные СЗ (САНУР, Горный гектар, Метр, ВиноГрад) | В таблице: бренд + ИНН/СЗ |

| **Первогорье цены Vladis** | Выбросы «от 1,6 до 79 млн», avg 149k — мусор агрегатора | Этажи / jilfond / сайт |
| **Город Гор ₽/м²** | 237 (ЦИАН) vs 229–289 (m2) vs 285+ (МОРЕИН каталог) | Диапазон + дата; не одна «истина» |
