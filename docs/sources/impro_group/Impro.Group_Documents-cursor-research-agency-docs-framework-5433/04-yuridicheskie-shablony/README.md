# 04. Юридические шаблоны

## Что это
Готовые тексты договоров и приложений для клиентов и подрядчиков.

## Зачем
Единый стандарт вместо «каждый раз с нуля». Защита денег, сроков и прав.

## Что входит (к наполнению)

| Документ | Зачем | Приоритет |
|----------|-------|-----------|
| `kak-my-dogovarivaemsya.md` | Логика: рамочный договор + приложение | P0 |
| `shablony/dogovor-uslug.md` | Рамочный договор | P0 |
| `shablony/prilozhenie-opisanie-rabot.md` | Конкретный проект (объём, сроки, цена) | P0 |
| `shablony/nda.md` | Неразглашение | P0 |
| `shablony/akt.md` | Приёмка | P0 |
| `shablony/izmenenie-obyoma.md` | Доп.работы / change request | P0 |
| `shablony/sla-podderzhka.md` | Поддержка | P0 |
| `shablony/dogovor-podryadchika.md` | ИП / самозанятый / подрядчик | P0 |
| `shablony/peredacha-prav.md` | Кому что принадлежит | P0 |
| `shablony/soglasie-pdn.md` | Если обрабатываем ПДн | P1 |

## Важно
Все шаблоны до утверждения юристом помечать: **черновик — согласовать с юристом**.
