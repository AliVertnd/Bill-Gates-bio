# Какие описания компании обычно бывают

Для агентства / консалтинга / product+IT партнёра рынок обычно держит:

1. **Платформа / кто мы** — миссия/суть, позиционирование, ценности, нарратив, «против чего», тон
2. **ICP / целевые клиенты** — для кого, ЛПР, отказы, отрасли
3. **Стратегия компании** — горизонт 12–24 мес, приоритеты, масштаб, экономика
4. **GTM / маркетинг себя** — каналы, лестница офферов, контент, сайт
5. Позже: tone of voice, брендбук, messaging pillars, proof points

Не нужно плодить отдельные файлы «миссия», «нарратив», «позиционирование», если они повторяют один утверждённый текст.

У Impro.group это сведено в `01-kompaniya/kto-my.md` + три соседних рабочих файла.
