# Кейсы агентств РФ: оргструктура, юрмодель, документы

> Research note · 2026-07-22

## 1. IT-Agency

**Тип:** performance / digital agency с сильной операционной культурой  
**Модель:** самоуправление, автономные бизнес-юниты, Совет агентства

### Что важно

- Нет классического гендиректора и жёсткой иерархии
- Направления = бизнес-юниты со своим P&L, наймом, бюджетом
- Совет агентства: по представителю от направлений + команда развития
- Shared services: продажи, маркетинг, HR, финансы
- OKR как синхронизация
- Распределение клиентского дохода по регламенту (маркетинг/продажи, дивиденды, фонд инициатив и т.д.)

### Документы / артефакты, которые подразумевает модель

- Положение о Совете
- P&L / правила распределения выручки
- OKR cadence
- SLA обработки лидов
- CRM-регламент
- Роли и грейды вместо «должностей ради должностей»

### Источники

- https://www.it-agency.ru/academy/it-agency-inside/
- https://companies.rbc.ru/news/4AyNl878KM/it-agency-kak-upravlyat-kompaniej-bez-generalnogo-direktora/

### Урок Impro.group

Автономию практик внедрять только вместе с финансовой прозрачностью и decision rights. Иначе получится «феодализм».

## 2. Notamedia

**Тип:** digital agency + IT-интегратор  
**Модель:** группа / два контура экспертизы

### Что важно

- Разделение agency и integrator
- Топ-команда + руководители направлений
- Для крупных проектов — крупные продуктовые команды

### Урок

Если Impro.group усиливает IT (интеграции, продукты, разработка), имеет смысл заранее проектировать отдельный IT-контур — хотя бы управленчески, позже юридически.

## 3. AGIMA

**Тип:** digital-интегратор  
**Модель:** независимые проектные офисы + партнёрская сеть

### Что важно

- Несколько проектных офисов, каждый ведёт портфель клиентов
- PM/офис отвечает за клиента end-to-end
- Масштаб через partners club

### Урок

Для Impro.group на росте: «клиентский owner» важнее, чем отдел ради отдела. Проектный офис / pod может быть единицей ответственности за маржу, сроки, NPS.

### Источники

- https://www.agima.ru/approach/
- https://partnersclub.digital/about

## 4. AIC

**Тип:** design / CX / digital consulting  
**Модель:** проектные команды + сильная культура качества

### Что важно

- Команды собираются под задачу клиента
- Принципы и quality doctrine важнее оргсхемы

### Урок

Для консалтингового контура Impro нужны: принципы решений, ревью, стандарты качества, а не только «кто кому подчиняется».

### Источники

- https://aic.ru/agency
- https://principles.aic.ru/

## 5. Red Keds

**Тип:** креативное агентство  
**Модель:** компактное ядро + внешняя сеть

### Что важно

- Небольшой штат
- Много внешних специалистов
- Нужна дисциплина канбана / команд, иначе хаос

### Урок

Contractor-first возможен, но только с пакетом: NDA, IP assignment, бриф, QA gates, contractor onboarding.

### Источники

- https://redkeds.com/company

## 7. Типовые модели оргструктуры в РФ-агентствах

По обзорам (в т.ч. eLama):

| Модель | Когда подходит |
|--------|----------------|
| Функциональная | До ~10–15 человек, мало параллельных клиентов |
| Проектная | Бутик, консалтинг, крупные уникальные проекты |
| Матричная | 3+ параллельных клиента, нужны стандарты профессии |
| Business-unit | Есть сильные лидеры направлений и P&L-дисциплина |
| Self-management | Зрелая культура, прозрачные финансы, фасилитация |

Источник: https://elama.ru/blog/struktura-marketingovogo-agentstva/

## 8. Документный минимум, который «зрелые» агентства РФ так или иначе имеют

### Corporate / HR

- Устав, протоколы, приказы
- Штатное расписание, ТД, ПВТР
- Положение об оплате / премировании
- Должностные инструкции или role cards
- NDA сотрудников, соглашения о РИД

### Client

- Договор оказания услуг + приложения
- NDA, бриф, ТЗ / backlog
- Акты, отчёты, SLA
- Change request / допсоглашения

### Compliance

- Политика ПДн, согласия, cookies
- Внутреннее положение по 152-ФЗ
- Реестр обработок / доступов

### Ops / Knowledge

- Регламенты продаж и delivery
- Прайс / калькулятор
- База знаний / wiki
- Кейсы и lessons learned
