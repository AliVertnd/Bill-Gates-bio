# Research блока 08 — рынок услуг, тренды, потребности mid-market

> Дата: 2026-07-27  
> Цель: дать основателям опору, пока «плавают» в рынке; заземлить каталог микроуслуг и вилки цен  
> Для Impro.group: связка маркетинг + IT + операции для компаний ~5–10 млн ₽/мес

---

## 1. Что происходит на рынке (2025–26)

### Тренды упаковки услуг (мир + РФ)

| Тренд | Суть | Вывод для нас |
|-------|------|----------------|
| **Productized services** | Атомы с фикс. scope и ценой → пакеты / ретейнеры | Ваша логика микроуслуг — в мейнстриме, не «изобретение» |
| **Гибрид retainer + milestone** | База за доступ/контур + отдельные продукт-пакеты | Ядро = ретейнер контура; атомы — внутри и как вход |
| **Прозрачный состав** | Клиент хочет видеть «за что платит», не «часы тумана» | Карточка атома: когда / кому / результат |
| **AI удешевляет рутину** | Отчёты, черновики, техаудиты дешевле; стратегия и внедрение дороже | Базу рутинных атомов не завышать; PMO и выбор направления — дороже |
| **Покупатель mid-market устал от роя подрядчиков** | Отдельные SEO / контекст / сайт / CRM без склейки | Наш голубой океан = склейка, не ещё один узкий прайс |

### Потребности клиента 5–10 млн ₽/мес (типовые)

1. Понять, **куда растить и что рискованно**, без «стратегии в стол».  
2. Связать маркетинг с CRM, сайтом, аналитикой, продажами.  
3. Контролировать подрядчиков из одной точки.  
4. Не купить «лиды под ключ», а получить управляемую систему.  
5. Стартовать с понятного первого шага (не сразу абонентка на 600к без доверия).

Это бьётся с утверждённым описанием Impro.group и остриём «контур внутри».

## 2. Красный океан: как продают «куски»

| Игрок | Типовой прайс | Где обрыв для mid-market |
|-------|---------------|---------------------------|
| SEO-агентство | 50–180к/мес ведение; аудит 25–80к | Нет IT/операций/выбора роста компании |
| Performance | Ведение от ~40–150к + медиабюджет | Канал без контура |
| Веб-студия | Сайт/лендинг проектно | Артефакт без роста |
| Интегратор | CRM/1С проектно | Система без маркетинга |
| Консалтинг | Стратегия 200–800к+ | Часто без рук |

**Impro.group** не конкурирует с ними «дешевле SEO».  
Конкурирует отсутствием обрыва: атомы тех же рынков **собираются в контур** с PMO и выбором направлений.

## 3. Ценовые вилки РФ (ориентиры для баз атомов)

> Источники: обзоры рынка SEO 2025–26 (SEOnews, отраслевые блоги), прайсы digital/маркетинг-агентств.  
> Это **не наш прайс**, а калибровочная сетка для `базовая_стоимость`.

### SEO
| Продукт | Вилка |
|---------|--------|
| Экспресс/тех. аудит | 25–80к |
| Аудит ниши / конкуренты | 40–120к |
| Семантика | от ~18–60к |
| Ведение малый | 50–120к/мес |
| Ведение средний / ecom | 70–180к/мес |
| Крупный / федеральный | от 180к/мес |
| Частый чек клиентов агентств | 50–100к/мес (SEOnews 2025) |

### Стратегия / аудит маркетинга (агентства полного цикла)
| Продукт | Вилка (примеры рынка) |
|---------|------------------------|
| Аудит маркетинга | от ~150–250к+ |
| Маркетинговая стратегия | от ~200–400к+ |
| Комплекс / аутсорс маркетинга | сотни тыс. ₽/мес |

### Performance / digital-пакеты
| Продукт | Вилка |
|---------|--------|
| Аудит рекламы | от ~15к |
| Ведение контекста/таргета | от ~40к/мес + бюджет |
| Пакеты «канал + лендинг» | от ~100–150к |

### Вывод для нашего ядра
- Вход **от 80к** — ниже «серьёзного» аудита полного цикла, но выше мусорных «аудитов за 15к»; ок как **вход в контур**, не как обесценивание экспертизы.  
- Ретейнер **~600к/мес** — это уже **не один канал**, а несколько слоёв + PMO; на рынке сопоставимо с «аутсорсом маркетинга / growth office», не с «просто SEO».  
- Если собрать только SEO-атомы на 100к — мы выглядим как агентство. Если SEO+CRM+аналитика+PMO+стратегический ритм → попадаем в свою категорию.

## 4. Как рынок режет услуги на микро (паттерн)

Почти везде одна схема:

```text
аудит/диагностика → стратегия/roadmap → внедрение атомов → ежемесячное ведение (отчёт + оптимизация)
```

Внутри канала (SEO/performance) атомы одни и те же:  
исследование → техника/настройка → контент/креатив → распространения → аналитика → отчёт.

**Мы добавляем слой**, которого нет у узких игроков:  
`связь с другими контурами` + `управление подрядчиками` + `выбор роста/рисков`.

## 5. Гипотезы каталога Impro.group (из research)

1. Витрина L2: **ретейнер контура** + **диагностический вход**.  
2. L1-каналы (SEO, performance, контент, разработка) — **внутри** контура или как модули с PMO, не как дешёвая витрина.  
3. Каждый атом несёт поля «когда / кому», иначе калькулятор не предложит состав по триггеру.  
4. Коэффициенты клиента обязательны: один и тот же SEO-пакет для простого B2B и девелопера с 3 ЖК — разная экономика.  
5. AI-рутину (черновик отчёта, первичный техаудит) закладывать в базу часов вниз; человеческий разбор рынка клиента — вверх.
