# 09. Финансы

## Что это
Как считаем стоимость, маржу, привлечение и как отчитываемся.

## Зачем
Формула маржи уже есть — делаем стандарт. Отчётность сейчас ломается — чиним здесь и в производстве.

## Зафиксированная формула (из ответов)

1. Считаем **себестоимость** работы  
2. Плюс **стоимость привлечения** клиента  
3. Смотрим относительно суммы договора  
4. Когда привлечение окупилось, дальше по **LTV** опираемся на себестоимость

Нужно превратить это в калькулятор и шаблон отчёта.
