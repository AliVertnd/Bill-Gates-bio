## Как читать

Три уровня:

1. **Линейка** — направление  
2. **Услуга** — то, что продаём клиенту  
3. **Мини-услуга** — из чего собирается оффер и калькулятор

## Первый шаг: как не подорвать концепт

Основатель сомневается в платном аудите как отдельном продукте.

### Рекомендация

```text
1) Бесплатное короткое знакомство (discovery)
   → проверяем fit, не делаем глубокий разбор бесплатно

2) Платный диагностический воркшоп (не «аудит ради аудита»)
   → совместное понимание + карта 30/60/90
   → цена от 140–250 тыс. ₽

3) Если заходите в ретейнер за 30–45 дней
   → стоимость воркшопа частично/полностью засчитывается в первый месяц
```

Так экспертиза не обесценивается, а клиент не чувствует, что «купил отчёт и всё».

### Формулировка для продажи

> Первый созвон — чтобы понять, есть ли смысл работать вместе.  
> Если видим потенциал — проводим диагностический воркшоп: разбираем маркетинг, IT, подрядчиков и собираем карту первых действий.  
> Если после этого заходим в работу, стоимость диагностики можно зачесть в первый месяц.

## Что не включать на старте

- задачи ниже минимального чека
- SMM / SEO / креатив / performance как одиночные дешёвые услуги «в вакууме»
- разовые консультации по часам без перехода в контур
- «сделаем любой сайт» без связки с ростом
- работа без доступа к данным и ЛПР

## Связь с калькулятором

Каждая **мини-услуга** = строка:

| Поле | Смысл |
|------|--------|
| Линейка / услуга / мини-услуга | что продаём |
| Роль | кто делает |
| Часы | трудоёмкость |
| Ставка | внутренняя или подряд |
| Сложность | коэф. 1.0–2.0 |
| Подряд | да / нет / частично |
| Себестоимость | часы×ставка×сложность + подряд |
| Управленческая наценка | за контроль и риски |
| Маржа | целевая |
| Итого | цена клиенту |
| Формат | разово / спринт / абонентка |

### Формула (черновик)

```text
Цена мини-услуги =
(внутренние часы × ставка × сложность × срочность)
+ себестоимость подрядчиков
+ управленческая наценка
+ маржа
```
