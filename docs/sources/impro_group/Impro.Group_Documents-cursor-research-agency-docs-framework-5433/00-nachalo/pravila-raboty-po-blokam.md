# Правила работы по блокам

> Как мы наполняем базу документов Impro.group

## Порядок блоков

Работаем **по одному блоку**.  
Блок `00-nachalo` заполняем **последним** (когда остальные уже живые).

Рекомендуемый порядок:

1. `01-kompaniya` — кто мы, стратегия, позиционирование, развитие  
2. `08-uslugi-i-produkty` — фиксация услуг и продуктов  
3. `05-prodazhi` — стратегия продаж + логика продажи + воронка  
4. `09-finansy` — цены, маржа, отчёты  
5. `04-yuridicheskie-shablony` — договоры  
6. `06-proizvodstvo` — как делаем  
7. `07-metodologii` — как думаем (**максимум исследования**)  
8. `02-yur-struktura` — ИП/ООО/аккредитация  
9. `03-organizaciya-i-lyudi` — роли и люди  
10. `12-instrumenty` — CRM и инструменты  
11. `10-compliance` — данные и риски  
12. `11-baza-znaniy` — кейсы и уроки  
13. `00-nachalo` — финальная полировка входа и словаря  

Порядок можно сдвигать, если основатели скажут иначе.  
Важно: **один активный блок за раз**.

**Исключение — спринт:** если основатели утвердили роадмап на N дней (см. `roadmap-3-dnya-2026-07-27.md`), работаем **по цепочке зависимостей** (услуги → логика продажи → воронка → …), даже если за день затрагивается несколько папок. После спринта возвращаемся к правилу одного блока.

## Цикл работы внутри блока

```text
1. ИССЛЕДОВАНИЕ РЫНКА
   → изучаем успешные и слабые компании / практики
   → собираем референсы, ошибки, типовые документы
   → пишем research-файл в папке блока

2. ВОПРОСЫ ОСНОВАТЕЛЯМ
   → обширный список вопросов по блоку
   → основатель отвечает своим видением и наблюдениями

3. ЧЕРНОВИК ДОКУМЕНТОВ
   → собираем 1+ документов блока
   → опираемся на рынок + ваши ответы

4. ИТЕРАЦИИ
   → правки, уточняющие вопросы, новая версия
   → пока не скажете: «утверждаем»

5. СТАТУС «ДЕЙСТВУЕТ»
   → документ можно использовать в работе
   → переходим к следующему блоку
```

---

## Почему исследование — самый большой кусок

Мы стартуем с нуля.  
Нельзя «придумать из воздуха» стандарты, которые рынок уже обкатал.

Особенно критично исследование для:

- позиционирования и стратегии
- упаковки услуг
- логики продаж
- **методологий** (блок 07) — там исследование будет самым глубоким

Правило:  
**сначала смотрим, как делают другие → потом решаем, как делаем мы.**

---

## Что должно быть в research-файле блока

1. Какие компании/практики смотрели  
2. Что у них работает  
3. Что не работает / типичные ошибки  
4. Какие документы у них обычно есть  
5. Гипотезы для Impro.group  
6. Список вопросов основателям  

---

## Формат ответов основателя

Можно отвечать:

- списком
- голосом → текстом
- «не знаю / надо решить»
- примерами из ваших проектов
- «мне нравится вариант А из research»

Неполные ответы тоже полезны — дожимаем во второй итерации.
