# Как пользоваться базой

1. Ищите нужный блок по номеру папки (`01` … `12`).  
2. В каждом блоке откройте `README.md` — там список документов и приоритеты.  
3. Если документа ещё нет — это нормально: сначала скелет, потом наполнение.  
4. Непонятный термин — в [словаре](slovar-terminov.md).  
5. Новые решения основателей — в `zhurnal-reshenij.md` (создадим при первом решении).

## Владелец базы

Основатель (зафиксировано в ответах).

## Язык

Только русский. Английские термины всегда поясняем по-русски.
