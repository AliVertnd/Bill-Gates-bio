# Словарь терминов

Все формулировки — простыми словами. Английские сокращения раскрываем.

| Термин | Что это значит |
|--------|----------------|
| **Impro.group** | Наш бренд и компания. Не путать с impro.pro (конкурент) |
| **Handbook / база документов** | Единая папка/репозиторий правил и шаблонов компании |
| **Скелет** | Структура папок и список документов без полного наполнения |
| **P0 / P1 / P2** | Приоритет: срочно / важно скоро / для масштаба |
| **ИП** | Индивидуальный предприниматель |
| **ООО** | Общество с ограниченной ответственностью |
| **Самозанятость (НПД)** | Налог на профессиональный доход для физлица |
| **Корпоративный договор** | Письменная договорённость учредителей о долях, решениях, выходе |
| **IT-аккредитация Минцифры** | Госстатус IT-компании в РФ, нужен для льгот |
| **Сколково** | Инновационный центр; резидентство даёт льготы/поддержку проектам |
| **Грант** | Безвозмездное финансирование под проект/продукт от фонда |
| **НДС** | Налог на добавленную стоимость |
| **44-ФЗ / 223-ФЗ** | Законы о госзакупках и закупках отдельных юрлиц (тендеры) |
| **Рамочный договор** | Общий договор на сотрудничество |
| **Приложение / ТЗ / описание работ** | Конкретика по одному проекту: что, сроки, цена |
| **NDA** | Соглашение о неразглашении конфиденциальной информации |
| **Акт** | Документ приёмки работ / закрытия этапа |
| **SLA** | Условия поддержки: сроки реакции, что входит |
| **Change request / изменение объёма** | Письменный запрос клиента на доп.работы с пересчётом |
| **Scope / объём работ** | Что входит в проект и что не входит |
| **IP / права на результат** | Кому принадлежат код, дизайн, тексты, методологии |
| **Reusable IP** | То, что остаётся у агентства и можно использовать снова |
| **MSA + SOW** | Связка: рамочный договор + приложение по проекту (мировая практика) |
| **КП** | Коммерческое предложение |
| **CRM** | Система учёта клиентов и сделок |
| **Воронка продаж** | Этапы от лида до оплаты |
| **Лид** | Потенциальный клиент / заявка |
| **Квалификация** | Проверка: наш ли это клиент и задача |
| **Discovery** | Глубинное интервью / диагностика до КП |
| **ICP / портрет клиента** | Описание идеального клиента |
| **SMB / mid-market / enterprise** | Малый / средний / крупный бизнес |
| **Онбординг** | Ввод клиента или сотрудника в работу |
| **Оффбординг** | Корректное завершение работы |
| **Kickoff** | Стартовая встреча по проекту |
| **Плейбук** | Сценарий «как мы делаем такой тип работы» |
| **SOP / регламент** | Пошаговая инструкция повторяемого процесса |
| **RACI** | Кто отвечает / кто делает / кого спрашивают / кого информируют |
| **Ретейнер** | Ежемесячная оплата за регулярную работу |
| **SaaS** | Свой софт по подписке |
| **Себестоимость** | Наши затраты на выполнение работы |
| **Маржа** | Остаток после затрат |
| **Стоимость привлечения** | Затраты на получение клиента |
| **LTV** | Сколько клиент приносит за всё время |
| **P&L** | Отчёт о прибылях и убытках |
| **Utilization** | Загрузка людей оплачиваемой работой |
| **Дебиторка** | Сколько клиенты должны нам |
| **152-ФЗ** | Закон о персональных данных в РФ |
| **ПДн** | Персональные данные |
| **Compliance** | Соответствие законам и внутренним правилам |
| **Accountability chart / карта ролей** | Схема: какое «кресло» за какой результат отвечает |
| **Practice / практика / направление** | Профессиональный блок (разработка, маркетинг и т.д.) |
| **Shared services** | Общие функции: финансы, юр, HR, продажи |
| **Pod / проектная команда** | Команда под клиента/проект |
| **OKR** | Цели и ключевые результаты на период |
| **Scorecard** | Короткая таблица метрик (еженедельно) |
| **ADR / журнал решений** | Короткая запись: что решили и почему |
| **Sanitized кейс** | Кейс без секретов клиента |
| **Productized offer** | Упакованная услуга с понятной ценой и составом |
