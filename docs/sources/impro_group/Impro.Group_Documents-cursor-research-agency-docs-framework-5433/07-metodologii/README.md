# 07. Методологии

## Что это
Как мы думаем и решаем задачи: подходы, а не разовые инструкции.

## Зачем
Нормальных методологий пока нет. Это будущий актив компании (должен принадлежать юрлицу/ИП).

## Важно
Это **самый research-тяжёлый блок**.  
Перед написанием документов — глубокое исследование чужих методологий (РФ и мир), разбор сильных и слабых подходов, только потом — наш стандарт.
