## 1. Стратегическая идея GTM

Категории «контурный партнёр» в голове клиента ещё нет — **входящего спроса ждать нельзя**.  
Мы сами объясняем категорию через холодку, контент и сайт, создавая голубой океан в восприятии среднего бизнеса.

Цель экономики: ретейнер контура ~600к/мес.  
Временная модель входа *(фиксируем, будем менять)*:  
знакомство → диагностика/разбор (от 80к, возможен зачёт) → ретейнер.

## 4. Воронка касания *(черновик)*

1. Индивидуальное касание из холодки / контента  
2. Созвон-знакомство (fit)  
3. Второй созвон с выводами первичного разбора  
4. Диагностика / входной пакет  
5. Ретейнер контура  

Точный оффер письма и состав 80к — дособрать в блоке услуг + продажах.

## 5. Контент

- экспертные статьи, переосмысление Хабр/VC/GitHub  
- разборы мировых кейсов  
- свои медиа / контент-завод (длинные + нарезки) — длинная игра + охваты  

Задача контента: **научить рынок новой категории**, не только «продать услугу».

Время ответа; контроль выполнения; клиентский кабинет; только проверенная информация; отчёты; предупреждения об узких местах.
