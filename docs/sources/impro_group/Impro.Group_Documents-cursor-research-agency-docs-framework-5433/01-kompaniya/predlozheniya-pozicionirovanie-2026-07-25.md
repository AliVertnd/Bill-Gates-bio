## Что изменилось в v3 (почему меньше «воды»)

| Было (слабо) | Стало (жёстче) |
|--------------|----------------|
| «Управляемый рост», «усиливаем», «партнёр» | Конкретный механизм: выбор направления → внедрение внутри контура |
| Ценности-прилагательные | Правила: что делаем / чего не делаем |
| Абстрактный «нет аналога» | Таблица: агентство / студия / интегратор / консультант / аутстафф — где у каждого обрыв |
| Мягкое остриё про «подрядчика» | «Не подряд снаружи. Контур внутри…» |
| Общий 30/60/90 | Артефакты на руках у ЛПР по срокам |
| — | Шпаргалка возражений (агентство / ретейнер / «просто сайт») |

## Если всё ещё «слабо»

Скажите **что именно** режет слух (миссия / остриё / ценности / океан) — точечно перепишу.  
Следующий прирост остроты даст блок **услуг** (`08`): там появятся «правда сейчас», пакет 80к и язык оффера без обобщений.
