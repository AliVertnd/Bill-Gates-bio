- **53 О1:** Сначала каталог услуг + мини-услуги + калькуляция — блокер для «правды уже сейчас».
- **54 О1:** Категория №5 ближе всего.
- **55 О1:** Девелопмент/строительство да; плюс IT/стартапы (Flowwow).
- **56 О1:** Контент-проекты = свои медиа + контент-завод (история, финансы, маркетинг, IT, игры; длинные + нарезки).
- **57 О1:** пусто.
- **58 О1:** метрики — см. п.16.
- **59 О1:** основная фраза + запасная A; ниши заходят.
