## ЦА — рабочая нарезка (скорректировано)
**Live / Dual-use / Invest × Local / Siberia / Federal**  
Приоритет по **деньгам на 220–280**: **S/F-Dual → Invest → L-Live affluent** (не средняя семья).  
«35% жить» из меморандума — гипотеза концепции; на этой цене локал «для жизни» = узкий слой с капиталом (вторичка/сертификат/бизнес/доход 120–400 тыс.), не массовый Алтай.

## GTM в одном абзаце
Пресейл = дефицит + фиксация цены; Local-канал нужен для быстрых первых броней (доверие), но креатив и медиабюджет не строить вокруг «средней семьи ГА»; ядро выручки — Dual/Invest Сибирь+федерал + affluent local; октябрь доказывает капитализацию; инвест — только с P&L 4–7% net.
