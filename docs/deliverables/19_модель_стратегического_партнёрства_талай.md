## 1. Цель

Получить на проекте «Талай» роль **стратегического партнёра по контуру**, а не подрядчика на поисковое продвижение и часы разработки:

- участие в стратегических решениях по маркетингу, цифровому и коммерческому контуру;
- ответственность за аналитику, отслеживание трендов, формирование стратегии;
- разработку и развитие IT- и маркетингового контура;
- контроль агентского канала по проекту;
- координацию подрядчиков из одной точки.

**Целевая экономика:**
- абонентское сопровождение **250–350 тыс. ₽/мес**;
- возможность ежемесячного добора услуг **150–350 тыс. ₽**;
- успех-бонус — только в безопасной форме (см. §6).

## 2. Формулировка мандата (как говорить)

> IMPRO отвечает за **единый маркетингово–IT–коммерческий контур запуска ЖК «Талай»**: стратегия и язык рынка, аналитика и тренды, архитектура цифрового контура, координация подрядчиков и агентского канала, еженедельный прогноз к цели 300 млн ₽ — **внутри команды Сибирь Девелопмент**, с правом останавливать токсичные формулировки и размытие приоритетов.

Четыре рычага, без которых роль не работает:

| Рычаг | Содержание |
|---|---|
| Стратегия | Канон «город-ворота», запреты, приоритеты сегментов |
| Данные | Поля брони, метки источников, дашборд, разбор отказов |
| Канал | Аккредитация агентств, обучение, лот-лист, контроль витрин |
| Подряд | Одна точка постановки задач медиа / SMM / наружке / части IT |

## 3. Как получить контроль (последовательность)

1. **Зайти через риск, не через прайс.**  
   План 300 млн ломается не «креативом», а каскадом: 25 броней к 30.09 → ипотека 45 дней → чужие обещания 13–18% → отдел из ~5 человек → хаос посредников.

2. **Просить роль на 90 дней, не контракт «навсегда».**  
   «Держатель контура на квартал запуска»: приоритеты, подрядчики, пилот агентств, аналитика, язык. Медиабюджет и комиссии агентств — за застройщиком.

3. **Закрепить артефакты власти** (иначе контроля не будет):
   - еженедельный коммерческий штаб (повестку ведёт IMPRO);
   - реестр формулировок (без согласования — не в эфир);
   - shortlist агентств (без аккредитации — нет лот-листа);
   - единый бриф подрядчикам через IMPRO;
   - доступ к учёту сделок и записи звонков по этапам воронки.

4. **База 250–350 тыс. = мозг и координация**, не полный «запуск под ключ».  
   Тяжёлое исполнение — в доборы.

5. **Через 60–90 дней** — апсейл по факту работы контура (рост базы или стабильные доборы).

## 4. Что входит в абонентку 250–350 тыс. ₽/мес (ядро)

| Блок | Содержание |
|---|---|
| Стратегия контура | Позиция, запреты, приоритеты сегментов, правки по рынку |
| Аналитика и тренды | Еженедельный срез воронки, отказов, конкурентов, сигналов рынка → 1–2 вывода для решений |
| Коммерческий контур | Прогноз к 300 млн, гейты 25 / 42 / 54 брони, повестка штаба |
| Контроль агентств | Пилот 2–3, регламент, обучение скрипту, контроль витрин (не замена отдела продаж) |
| Координация подрядчиков | Брифы, приёмка, приоритеты; закупка медиа — за клиентом |
| IT-архитектура (лёгкая) | Поля учёта, этапы, технические задания; не бесконечная разработка внутри базы |
| Риск-рамка | Право останавливать гарантии доходности и курортный язык |

**Не обещать в базе:** полный рекламный закуп «под ключ», весь продакшн, полный разбор всех звонков без лимита часов, тяжёлую разработку, гарантию 32 договоров долевого участия.

## 5. Ежемесячный добор 150–350 тыс. ₽ (меню)

| Добор | Когда включать | Ориентир |
|---|---|---|
| Ведение рекламных кабинетов / офис продвижения | Есть медиабюджет | 80–150 тыс. |
| Разбор звонков + правка скриптов | Отдел уже звонит | 40–80 тыс. |
| Продакшн / контент / бриф и приёмка наружки | Нужен объём креатива | 40–120 тыс. |
| IT-спринты (бронь, калькулятор, кабинет) | Есть бэклог | 60–150 тыс. |
| Расширение агентского канала / Сибирь | Локальный пилот стабилен | 40–80 тыс. |
| Сравнение управляющих компаний + материалы для инвестора | До выбора оператора | 40–70 тыс. |
| Спринт соцслушания | Всплеск возражений | 30–50 тыс. |

**Логика для клиента:** база = управление и ответственность; добор = руки под задачу месяца.  
Частый суммарный чек месяца — **400–700 тыс.**, но вход — **250–350 тыс.**

## 6. Оплата процентом от договора долевого участия

### Вердикт
**Как основную оплату — нет.  
Как узкий бонус сверху абонентки — допустимо.**

### Почему нельзя строить модель на % с каждого договора
- спор «чей клиент» (отдел продаж / агентство / реклама / самотёк);
- давление на скидки и на бронь любой ценой;
- риск токсичных обещаний доходности;
- споры при рассрочках, расторжениях, эскроу;
- для основателя «% со всего объёма» выглядит неоправданно дорого за координацию.

### Безопасные модели upside

| Модель | Описание |
|---|---|
| **Предпочтительно** | Абонентка 250–350 тыс. + доборы; квартальный бонус **фиксированной суммой** за гейты (25/42/54 брони, конверсия ≥60%) |
| **Допустимо** | + **0,3–0,7%** только от договоров, прошедших через аккредитованный агентский канал / метку IMPRO, после регистрации и без срыва брони |
| **Нельзя** | Процент со **всех** договоров проекта «за стратегию» без атрибуции |

Практичный гибрид:

> База **~300 тыс.** ₽/мес  
> + доборы по меню  
> + квартальный бонус **150–400 тыс.** за гейты  
> **или** 0,5% только с договоров канала пилотных агентств под регламентом IMPRO

## 8. Путь к одобрению: как сдвинуть мысль к стратегическому партнёрству

Ниже — рабочая схема: **как документами сподвигнуть на решение**, а не «продать пакет».

### 8.1. Принцип

Не начинать с цены.  
Начинать с **разрыва**: «система запуска не собрана» → «нужен держатель контура» → «вот роль на 90 дней» → «вот экономика 250–350 + доборы».

Документы играют разные роли:

| Документ | Роль в убеждении |
|---|---|
| Научное исследование | Статус экспертизы, доверие к методу |
| Прикладная записка (факты + рекомендации) | Повестка разбора и список решений |
| Этот документ (мандат) | Внутренняя упаковка IMPRO → короткая версия основателю |
| Карта инициатив / топ-12 | «Вот работы, которые уже названы — их должен кто-то держать» |

### 8.2. Сценарий встречи (45–60 минут) — мягкий

**Минуты 0–15. Факты.**  
Вестись по прикладной записке v1.1, часть I. Без продажи. Цель — согласие с рамкой рынка.

**Минуты 15–30. Приоритетные работы — очень аккуратно.**  
Не «вам нужен держатель контура», а:

> Из вашего плана запуска и этих фактов следует короткий список работ до пресейла. Их полезно не оставить между отделами.

Показать минимум из семи пунктов записки (язык, юррамка, учёт, скрипты, пилот АН, ипотека 45 дней, прогноз к 25 броням).  
Тон: очередность работ под гейты, не объём «пакета услуг».

**Минуты 30–45. Контур на 90 дней.**  

> IMPRO уже в связке с СД. На период запуска логично аккуратно расширить роль: стратегия языка, аналитика, учёт, пилот агентств, координация подрядчиков — рядом с вашей командой.  
> База 250–350 тыс. как развитие текущего мандата.  
> Дополнительные руки — по задаче месяца.  
> Успех удобнее связать с гейтами, не с процентом со всех договоров.

**Минуты 45–60. Фиксация.**  
Короткий протокол: согласны ли усилить контур на 90 дней; коридор базы; дата штаба; доступы; зачёт аналитики в первый месяц. Без жёсткого допроса «кто у вас за это отвечает».

### 8.3. Приёмы, которые сдвигают решение

1. **Сначала факты** — согласие с рамкой без разговора о деньгах.  
2. **Инициативы очень аккуратно** — как очередность работ из их плана, не как «купите пакет».  
3. **Зачёт исследования** — часть входа уже сделана.  
4. **Узкий вход** — 90 дней и 250–350 тыс., развитие текущего мандата.  
5. **Разделить бюджеты** — медиа и комиссии агентств отдельно.  
6. **Один лист основателю** после мягкого «да» маркетинга: роль · 90 дней · база · доборы · что не обещаем.

### 8.4. Чего не делать на встрече

- не начинать с цены абонентки;
- не ставить клиента в угол вопросом «а кто у вас за это отвечает?»;
- не обещать 32 договора «под ключ»;
- не предлагать % со всех ДДУ как основу;
- не вываливать 50 инициатив;
- не спорить с меморандумом — опираться на него и усиливать.

### 8.5. Критерий «одобрение получено»

Считается успехом, если в протоколе есть хотя бы:
1. роль IMPRO как держателя контура на 90 дней — **да**;  
2. база в диапазоне **250–350 тыс.** — согласована к выносу основателю / утверждена;  
3. пилот агентств и реестр формулировок — под контролем IMPRO;  
4. еженедельный штаб с повесткой IMPRO — назначен.

## 9. Одностраничник для основателя (текст)

**Роль.** IMPRO — стратегический партнёр по маркетингово–IT–коммерческому контуру запуска «Талай» на 90 дней.

**Зачем.** Цель ≥300 млн ₽ договоров к 31.12.2026 при отделе ~5 человек не закрывается поисковым продвижением и разовыми подрядчиками. Нужна одна точка: язык, данные, агентства, подряд, прогноз.

**Что делаем.** Стратегия и запреты формулировок; аналитика и тренды; архитектура учёта; пилот 2–3 агентства; координация подрядчиков; еженедельный штаб к гейтам 25 / 42 / 54 брони.

**Что не делаем.** Не гарантируем сделки «под ключ». Не обещаем доходность покупателям. Медиабюджет и комиссии агентств — отдельные строки застройщика.

**Экономика.** Абонентка 250–350 тыс. ₽/мес + доборы 150–350 тыс. по задаче месяца. Успех — бонус за гейты или узкий % только с атрибутируемого агентского канала (по желанию). Зачёт уже выполненной аналитики — в первый месяц.

**Решение.** Утвердить роль на 90 дней · базу · дату штаба · доступ к учёту.
