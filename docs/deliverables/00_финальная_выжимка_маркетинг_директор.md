## 2. Рыночная рамка (коротко)

Горно-Алтайск — **не курорт**. Это **ворота**: аэропорт + единственная столица + сервисы. Манжерок/Чемал/Катунь — дальше.

| Факт | Цифра | Следствие |
|---|---|---|
| Население ГА | 63 848 (↓) | Нет демографического бума |
| Миграция РА | −361…−497 (2022–24) | Спрос не из «всех переезжают» |
| ЗП РА / душевой доход | ~75к / ~48к | Средняя семья не тянет 9–11 млн без капитала |
| КСР ночёвки Майма / ГА | 713к / 122к (2025) | Тур в агломерации; город слабее курортного контура |
| Турпоток РА | 2,8 млн (2025), ~+5% план 2026 | Драйвер региона; ~70% — авто из Сибири |
| Аэропорт | ~0,5 млн → цель 1,3+ к ~2028 | Усиление gateway |
| Экспозиция | 786 лотов / 12 проектов (мемо) | Crowded market |
| Распроданность РА | −47,8% г/г (Домклик) | Завышенные цены рынок уже наказал |

**Цена «Талая»:** пресейл **228** — рыночный вход в качественный городской продукт. Старт **253** — премия: защищать продуктом и темпом, не слоганом «Алтай всегда дорожает».

## 3. Кто покупает на 220–280

**Не** массовый локал «просто жить».  
**Да** — **Invest + Dual-use** + узкий affluent local.

Арендная экономика gateway (модель): base net часто **~4–9%**; stress ~2–3%. Это **не** 15–18% из апарт-презентаций.  
В коммуникации до выбора УК: доходность только **как сценарий**, без гарантий. УК — shortlist из нескольких; дом ещё не в продаже.

ОП на старте ~**5** человек → критичны скрипты, SLA и партнёрский канал АН.

## 8. Контур IMPRO (канон из модели агентства)

**Категория IMPRO:** встроенный партнёр по маркетингово–IT-контуру (не «ещё SEO-агентство»).  
**Ядро модели:** ретейнер **~600к/мес**; текущие **200к** = SEO + dev (слой L1).  
**Цель для «Талай»:** L2 **600 / ~750 / 850–900** (Base / Launch / Control). Медиа — **отдельно**.

5 блоков: управление развитием · архитектура · исследования · аналитика · реализация.

Вход: discovery → воркshop 140–300к (зачёт в 1-й месяц) → ретейнер.  
Стратегия контура «Талай» в workspace — база для встречи; предложить **зачёт** при апгрейде.

**Рекомендация на MD:** выносить основателю **Launch ~750к** + медиа.

## 9. Решения на встрече с маркетинг-директором

1. Согласны ли с рамкой **gateway + Invest/Dual-use как ядро**?  
2. Утверждаем ли запрет гарантий доходности до выбора УК?  
3. Даём ли добро на пилот **2–3 АН** и условия комиссии?  
4. Кого из УК уже рассматривает СД — добавить в сравнение IMPRO?  
5. **Медиабюджет отдельно** — какая сумма на «Талай»?  
6. **Апгрейд 200к → Launch ~750к** (или Base/Control) — что выносим основателю?  
7. **Зачёт** уже сделанной стратегии в 1-й месяц ретейнера — ок?
