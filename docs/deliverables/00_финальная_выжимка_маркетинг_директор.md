## 2. Рыночная рамка (коротко)

Горно-Алтайск — **не курорт**. Это **ворота**: аэропорт + единственная столица + сервисы. Манжерок/Чемал/Катунь — дальше.

| Население ГА | 63 848 (↓) | Нет демографического бума |

**Цена «Талая»:** пресейл **228** — рыночный вход в качественный городской продукт (Домклик ~227). Старт **253** — премия: защищать продуктом, темпом и доказанной капитализацией, не слоганом «Алтай всегда дорожает».

## 3. Кто покупает на 220–280

**Не** массовый локал «просто жить».  
**Да** — **Invest + Dual-use** (себе несколько раз в год + сдача простоев) + узкий affluent local (вторичка / сертификат 15–18 млн / бизнес / returnees).

Мотивы города (не курорта): первая/последняя ночь у аэропорта, ранний вылет, магазины/РКБ, командировки, кадры Манжерока, студенты.

Арендная экономика gateway (модель): base net часто **~4–9%** на чеке 7,5–10,5 млн; stress ~2–3%. Это **не** 15–18% из апарт-презентаций. Long-term 35–60к/мес даёт fallback ~4–7%.

**Амаду (Брусника)** — старт продаж ~3кв2026: главный будущий конкурент по бренду.  
Окно «Талая»: выйти раньше, закрепить **жилой статус + optional УК** без отельной премии.

Публичных темпов ДДУ по объектам нет — риск: конкурируем с экспозицией, не зная, кто реально продаёт.

## 7. GTM до 300 млн (эскиз)

- Сен: пресейл 228 + бронь 100к / фиксация 45 дней.  
- Окт–дек: прайс 253 + доказанная капитализация первыми ДДУ.  
- Медиамикс по деньгам: Siberia + Federal Invest/Dual; Local — доверие и скорость, не «средняя семья».  
- Нужно порядка **~30 ДДУ** при чеке ~10 млн → плотная квалификация, не широкий охват.  
- АКАР-контекст: бюджеты девелоперов сжимаются → ставка на performance и качество лида.
