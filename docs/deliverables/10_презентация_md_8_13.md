**Вывод:** расти можно за счёт **туризма + инфраструктуры + межрегиона**, не за счёт прироста жителей.

## Слайд 4 — Горно-Алтайск = ворота, не курорт

```
Аэропорт + столица + сервисы     →   «Талай» = городская база
         ↓
   Манжерок / Чемал / Катунь     →   курорт дальше
```

| Верно говорить | Опасно говорить |
|---|---|
| Городская база Алтая у аэропорта | «Квартира на курорте» |
| Жить / приезжать / сдавать | «15% годовых гарантия» |
| Жилой статус + optional УК | Конкуренция 1:1 с апартами 450–625+/м² |

**Аналогии:** Canmore у Banff · жильё у аэропорта Queenstown.  
**Антипример:** Минеральные Воды — аэропорт есть, а спрос уезжает, если в городе нет причины остаться. У ГА причина есть.
