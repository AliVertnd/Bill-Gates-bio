# 1. Теории и рамки (ядро экспертизы)

### Т1. Горно-Алтайск = ворота Алтая, не курорт
Город даёт аэропорт, столицу, сервисы, РКБ, вуз. Манжерок / Чемал / Катунь — другой сценарий покупки и другая полка цен.  
**Следствие:** «Талай» = городская база (жить / приезжать / сдавать), не «квартира у подъёмника».  
**Антипример:** Минеральные Воды — сильный аэропорт без причины остаться.

### Т2. Спрос на «Талай» не демографический
Население города не растёт бумом; миграция региона отрицательная; средняя зарплата не тянет чек 9–11 млн.  
**Следствие:** выручка идёт из капитала, межрегиона и сценариев «вторая квартира / сдача», а не из «все переезжают жить».

### Т3. Две вселенные цен — не смешивать
- Оферты Домклик (якорь пресейла **226,7**)  
- Сделки Росстат / ЦБ (другие срезы)  
**Следствие:** пресейл **228** = вход в качественную городскую полку; **253** = премия, которую защищают темпом и первыми ДДУ, не слоганом.

### Т4. Честная арендная экономика vs апарт-маркетинг
Городской ADR и загрузка дают коридор порядка **~4–7,5% net** на среднем чеке пресейла (~9,4 млн) — сценарии после УК, не гарантия.  
Апарты продают **13–18%** и другой ADR. Копировать их язык = потерять доверие.

### Т5. План броней ≠ структура выручки
Мемо: гео броней **52% локал / 37% Сибирь / 11% внешние** — это **штуки**.  
Гипотеза IMPRO: в **деньгах** сильнее двойное использование + инвестиционный сценарий. Нужны поля учёта с дня 1.

### Т6. Окно сен–дек = захват → защита
Сен–окт: закрепить брони и нарратив до шума **Амаду**.  
Ноя–дек: защищать внимание против Амаду / Олимпа / Город Гор.

### Т7. Свободная ниша
Жилой статус + опциональная УК **без** отельной премии — пока свободна.  
Ниша между Маймой (масс) и апарт-полкой (450–625 тыс. ₽/м²).

### Т8. Контур важнее канала
При ОП ~5 и KPI 300 млн разовые подрядчики в «десяти чатах» не удерживают систему до ДДУ. Нужна одна связка: маркетинг ↔ учёт ↔ продажи ↔ агентства ↔ формулировки.

# 2. Реестр гипотез (сжато, по-русски)

Проверка почти всех ключевых гипотез — на **первых 25 платных бронях** и CRM-полях.

## 2.1. Рынок и цена

| Код | Гипотеза | Как опровергнуть |
|---|---|---|
| **H1** | Ядро выручки — межрегион / двойное использование / капитал, не демография | ≥50% ДДУ = жители РА без внешнего дохода/капитала |
| **H2** | Пресейл 228 = нормальная полка качественного города | Реальные сделки сопоставимых МКД устойчиво <200 при том же продукте |
| **H3** | «Центр ~277» Росстата — выброс, не цена ГА | Последующие кварталы держат «центр» ≥250 на большом числе сделок |
| **H4** | Главный риск пресейла — охлаждение распроданности (−47,8%) | Темп ДДУ/распроданность разворачивается вверх во 2П’26 |
| **H5** | Семейная ипотека 6 млн делает чек комбо-зависимым | >40% сделок — чистая семейная без комбо при чеке ≥9,4 |
| **H6** | Тур/аэропорт кормят dual и посутку; КСР растёт в Майме, не в ГА | КСР/загрузка города растут темпом Маймы |
| **H7** | Бум ввода 2025 ≈ ИЖС; угроза МКД меньше, чем кажется по «вводу всего» | Доля МКД показывает явный пересток квартир |

## 2.2. Ворота и продукт

| Код | Гипотеза | Как опровергнуть |
|---|---|---|
| **H-G1** | ≥60% сделок по намерению = инвестиция + двойное использование | После 25–40 ДДУ «жить постоянно локально» >50% без dual/invest |
