## 0. Зачем этот документ

Мы не пришли «продавать пакет». Мы собрали **открытый слой данных** по рынку Горно-Алтайска / Республики Алтай, сверили его с вашими **меморандумами запуска** и подготовили рамку для разговора:

1. Что реально говорит рынок про цену, спрос и конкурентов.  
2. Кто, скорее всего, купит «Талай» на полке 220–280 тыс. ₽/м².  
3. Как позиционировать проект, чтобы не конкурировать с Манжероком «в лоб».  
4. Какие пробелы данных ещё нужно закрыть вместе с вами.  
5. Какие улучшения контура (маркетинг / IT / продажи) логично обсудить до 1 сентября.

**Как читать:**

| Метка | Значение |
|---|---|
| **Факт** | Подтверждено источником (Росстат, меморандум, открытый рынок) |
| **Вывод IMPRO** | Наша интерпретация фактов |
| **Гипотеза** | Рабочая рамка — проверить на первых бронях / ваших данных |

**Канон продукта и цены:** ваши меморандумы (`docs/sources/00–02`).  
**Не канон:** материалы корп. GPT (`bg_*`) — используем только там, где совпадают с меморандумами.  
**Ограничение:** нет помесячных ДДУ по РА в открытом доступе; нет вашей CRM-выгрузки и медиабюджета — эти места помечены.

## 1. Executive summary

### 1.1. Пять главных выводов

1. **Горно-Алтайск — ворота Алтая, не курорт.** Аэропорт + столица + сервисы. Манжерок / Чемал / Катунь — дальше. Продавать «Талай» как ski/apart у подъёмника — ошибка позиционирования.  
2. **На полке 220–280 тыс. ₽/м² массовый локальный «просто жить» не тянет чек 9–11 млн** без капитала. Ядро выручки, по экономике и миксу лотов (82,5% студии+1к), вероятнее **Invest + Dual-use** + узкий affluent local. Доля «~35% жить» из меморандума — **гипотеза концепции**, не факт рынка.  
3. **Пресейл 228 — рыночный вход** в качественный городской продукт (Домклик ~226,7). **253 — премия**, которую нужно заслужить темпом, продуктом и доказанной капитализацией, а не слоганом «Алтай всегда дорожает».  
4. **Арендная экономика gateway честнее апарт-презентаций:** в нашей модели base net часто **~4–9%**, не 15–18%. До выбора УК доходность в коммуникации — только сценарии.  
5. **KPI ≥300 млн ДДУ к 31.12.2026** (~30–32 сделки) реалистичен при плотной квалификации и сильном межрегиональном контуре; публичных темпов ДДУ конкурентов нет — это главный data gap.

## 3. Рынок: hard data

**Источники:** Росстат / BD PMO, перекрёстные официальные цитаты, Домклик→РБК, МЭР РА / Толк / Интерфакс. Часть Fedstat UI из среды недоступна (403) — обошли XLSX и индексами.

### 3.1. Демография и доходы

| Показатель | Цифра | Следствие |
|---|---|---|
| Население ГА | **63 848** (↓) | Нет демобума |
| РА | ~210 тыс. | Узкий локальный рынок |
| Миграция РА | −361…−497 (2022–24) | Спрос ≠ «все переезжают» |
| ЗП РА / ГА | ~75к / ~86,5к | Средняя семья не тянет 9–11 млн без капитала |
| Душевой доход РА | ~48к | То же |

**Вывод IMPRO:** локальный «жить» на этой цене — **узкий affluent** (вторичка, сертификат 15–18 млн, бизнес, returnees с доходом 120–400к/мес — как в самом меморандуме), не массовый Алтай.

### 3.2. Туризм и размещение

| Показатель | Цифра | Источник |
|---|---|---|
| Турпоток РА | **2,8 млн** (2025), план +~5% на 2026 | МЭР РА / Толк |
| География гостей | ~**70%** авто из Сибири | власти РА |
| КСР ночёвки Майма | **713к** (2025) | Росстат ряд |
| КСР ночёвки ГА | **122к** | Росстат ряд |
| Аэропорт | ~0,5 млн → цель **1,3+** к ~2028 | Интерфакс / планы |
| Манжерок зима | 530+ тыс. посещений сезона | СМИ / Сбер |

**Вывод IMPRO:** тур растёт в **агломерации**, но город по КСР слабее курортного контура. «Талай» выигрывает как **база у ворот**, не как замена Манжерока.

### 3.3. Цены и распроданность

| Показатель | Цифра | Источник |
|---|---|---|
| Медиана новостроек ГА «у природы» | **226,7** тыс. ₽/м² | Домклик → РБК, апр. 2026 |
| Росстат первичка РА Q4’25 | **171** тыс. ₽/м² | Росстат |
| Распроданность РА | **−47,8%** г/г | Домклик → РБК |
| Экспозиция (мемо) | **786** лотов / **12** проектов | меморандум |

**Вывод IMPRO:** 228 — market-fit. 253 — премия в рынке, который уже наказывал за завышение. Коммуникация цены: «вход в качественный городской продукт **ниже апарт-полки в 1,8–2,6×**», не «Алтай всегда дорожает».

## 4. Кто покупает: сегменты и JTBD

### 4.1. Коррекция матрицы меморандума

Меморандум задаёт доли: жить ~35%, семья ~25%, dual ~20%, invest ~20%.  
**Метка:** гипотеза концепции до 25 броней (меморандум сам это фиксирует).

| Наша рамка для старта «Талая» | Почему |
|---|---|
| **Invest + Dual-use = большинство по намерению** (часто ≥60–70% сделок) | 82,5% компактных лотов; чек 9–11 млн; доходы локала | 
| Affluent local | Узкий, но важен для **скорости первых броней** (доверие) |
| Массовый «жить на средней ЗП» | Не core на 220–280 |

Это **гипотеза IMPRO** для обсуждения — не опровержение меморандума, а приоритизация выручки и креатива.

## 5. Арендная экономика (модель IMPRO)

**Файл:** `docs/working/06_gateway_rental_model.md`, `data/rental_model_summary.csv`.

| Что hard | Что assumption |
|---|---|
| Asking ADR ГА часто 4,2–5к (витрина 2,5–7к) | Achieved ADR = asking |
| Long-term ГА часто 32–60к+/мес | Occupancy 35 / 45–55 / 60% |

**Net yield к чеку 9,44 млн (после УК+комм+6%):** stress ~2–3%; base low ~4–5%; base high ~8–9%; optimistic ~10–11%.  
**Long-term fallback:** ~4–7% при 35–60к/мес.

**Вывод для коммуникации:**

> Городская база у аэропорта. Доходность — **диапазон сценариев** после выбора УК, не гарантия. Не сравниваем 1:1 с апарт-презентациями 15–18%.

**К обсуждению:** ваш shortlist УК; можно ли вообще показывать цифры до выбора оператора.
