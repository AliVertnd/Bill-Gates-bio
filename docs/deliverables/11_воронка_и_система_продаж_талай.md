## 1. Обратная воронка: ДДУ ← бронь ← встреча ← квалиф. лид ← сырой лид

### 1.1. Логика расчёта

Строим от якоря **32 ДДУ**. Этап «бронь» фиксирован каноном (**54**, CR ≥60%). Ниже броней — **диапазоны**, потому что CRM «Талая» пока нет: часть коэффициентов — **отраслевые нормы первички РФ / региональных ЖК**, не факты Талая.

| Этап | Определение (операционное) | Канон / расчёт |
|---|---|---|
| **ДДУ** | Зарегистрированный ДДУ в периоде Окт–Дек | **32** |
| **Квалиф. платная бронь** | Договор брони 100к, лот+цена+способ оплаты+дата ДДУ | **54** |
| **Встреча / консультация** | Проведённая (не только назначенная) презентация: ОП, шоу-рум, Zoom, выезд брокера | Диапазон |
| **Квалифицированный лид (MQL→SQL)** | Бюджет/ПВ подтверждён словами + интерес к конкретному формату + контакт в CRM с источником | Диапазон |
| **Сырой лид** | Любая заявка / звонок / входящий от АН с контактом | Диапазон |

## 2. Ёмкость ОП из 5 менеджеров

### 2.1. Нормы нагрузки (*отрасль, не факт Талая*)

Типичная норма менеджера первичных продаж (региональный ЖК, смешанный inbound + АН), **на 1 FTE / неделю** (5 рабочих дней):

| Активность | Низкая | Норма | Высокая | Комментарий |
|---|---:|---:|---:|---|
| Исходящие/входящие контакты (звонки + мессенджеры с фиксацией в CRM) | 80 | **120–150** | 180+ | Не «автодозвон», а осмысленные попытки |
| Квалифицирующие разговоры ≥3 мин | 25 | **35–45** | 55 | |
| Назначенные встречи | 4 | **6–8** | 10 | Show-rate *норма* 70–85% |
| Проведённые встречи | 3 | **5–6** | 8 | Включая Zoom для Сибири/Мск |
| Сопровождение броней / ипотека / документы | 30–40% времени | | | На этапе Окт–Дек доля растёт |

### 2.2. Ёмкость команды ×5

| Метрика / неделя | Консервативно | База | Потолок |
|---|---:|---:|---:|
| Контакты | 400 | **600–750** | 900 |
| Квалиф. разговоры | 125 | **175–225** | 275 |
| Проведённые встречи | 15 | **25–30** | 40 |
| Новые платные брони (если CR встреча→бронь ~45–55%) | 7–8 | **11–16** | 20+ |

**Горизонт сен–ноя ≈ 13 рабочих недель** (с учётом праздников/выездов — ближе к 11–12 эффективных):

| | Консервативно | База | Потолок |
|---|---:|---:|---:|
| Встречи за период | ~165–180 | **275–360** | 440+ |
| Потребность воронки (база) | | **100–120** | |
| Запас ёмкости встреч | | **×2,3–3** | |

**Вывод:** при 5 FTE **узкое место не в количестве встреч**, а в (1) качестве и скорости лида, (2) ипотечном контуре, (3) дисциплине доведения брони до ДДУ, (4) партнёрском потоке АН без хаоса в CRM.

### 2.3. Роли внутри ОП (рекомендуемая нарезка)

| Роль | FTE | Фокус |
|---|---:|---|
| Менеджер Local (ГА / РА) | 2 | Жить / семья, сертификаты, офлайн, шоу-рум |
| Менеджер Siberia | 1–2 | НСК / Барнаул / Кемерово, Zoom + брокер-туры |
| Менеджер Invest / АН-desk | 1 | Федеральные брокеры, Dual/Invest, контроль партнёрских сделок |
| Ипотечный контур | 0,5–1 (совмещённо или внешний брокер) | SLA банк ↔ клиент в окне 45 дней |

Без выделенного ипотечного владельца CR бронь→ДДУ **систематически** уходит ниже 60% (*отраслевое наблюдение*).

### 2.4. SLA команды (операционный минимум)

| Событие | SLA |
|---|---|
| Ответ на новый лид | ≤ **15 мин** в рабочее время; ≤ 2 ч вечером |
| Квалификация / отказ в CRM | в день контакта |
| Назначение встречи после SQL | ≤ **48 ч** |
| Выход на платную бронь после «горячей» встречи | ≤ **72 ч** (иначе лот «висит» бесплатно ≤3 дня) |
| Комплект документов в банк после брони | ≤ **5 раб. дней** |
| Еженедельный forecast к 300 млн | пн, владелец — рук. продаж |

### 3.2. Гипотеза источников внутри рынков

| Рынок | Собственный канал (сайт, ЦИАН/ЯН/Avito, digital, OOH, события) | Партнёры АН / брокеры | Логика |

| Канал | Local | Siberia | Federal | Σ | Доля |
|---|---:|---:|---:|---:|---:|
| Собственный | 16–18 | 8–10 | 1–2 | **25–30** | ~50% |

Это согласуется с рабочей гипотезой меморандума запуска: **~70% агентских / ~30% собственных сделок по ДДУ** — если считать, что АН сильнее доводят до регистрации. Для **броней** соотношение ближе к 50/50; для **ДДУ** сдвиг в пользу АН вероятен.

### 3.3. Партнёрский контур (из `08_…`)

**Пилот (не open market):**

| Приоритет | АН | Зачем |
|---|---|---|
| A | **Гравитон**, **АН «Республика»** | Единственные РГР ★ в ГА |
| A/B | **Риэлт-Лидер** | ГА + Чемал; dual-use нарратив |
| B–C | Остальные | Только после аккредитации |

**Правила партнёрки (операционные):**
1. Controlled open: 2–3 АН, единый прайс, бронь 100к, запрет «гарантированной доходности».  
2. KPI партнёра = квалиф. встречи и брони, не «лиды».  
3. Комиссия: шкала меморандума 3,5–4,5% + ретро 2% / 25 ДДУ в квартал — **к утверждению**; для Москвы 5–7% отдельно.  
4. Частные риэлторы — white-list 5–10 чел. через A-агентства, иначе CRM развалится при ОП=5.

### 3.4. Медиамикс (*гипотеза IMPRO, не утверждённый бюджет*)

Рабочий эскиз: **~40% Siberia digital · ~30% Federal/Invest · ~30% Local** (доверие и скорость).  
Local OOH (Russ / бывш. «Купол») — поддержка бренда, не драйвер Invest из НСК.

## 4. Ипотека и рассрочка: влияние на воронку и деньги

### 4.1. Правила продукта (канон)

| Инструмент | Условие | Эффект на цену / воронку |
|---|---|---|
| Базовая бронь 45 дней | В т.ч. ипотека **без** субсидирования | Цена пресейла/зафиксированная сохраняется |
| Субсидированная ипотека | Стоимость ↑ на сумму субсидии | Риск «шока» на встрече; скрипт обязателен до брони |
| Рассрочка 12 / 18 / 24 мес. | ПВ 30% или 50% | Цена ↑ на **3–11 тыс. ₽/м²** |
| Поэтапная рассрочка (после пресейла) | ПВ ≥30%; платёж 50/80/120 тыс. | Упрощает вход Local; снижает эскроу-кэш |
| 100% оплата ≤5 банк. дней | Скидка 250–500 тыс. | Ускоряет ДДУ и поступления |
| СВО | −3% при полном расчёте / ипотеке без субсидии | Не суммируется с другими акциями |
| Отказ банка (док.) | Полный возврат 100к за 10 раб. дней | Бронь «сгорает» без ДДУ — бьёт в CR |

### 4.2. Импликации для математики KPI

1. **ДДУ ≠ деньги на эскроу.** При 100% рассрочек с ПВ 30% первичные поступления ≈ **0,3 × объём ДДУ** (в модели запуска: от ~91 млн при полном сценарии рассрочек до ~305 млн при полной оплате/ипотеке). KPI «300 млн ДДУ» можно выполнить при слабом кэше — отдельно вести **прогноз эскроу**.  
2. **Окно 45 дней** ≈ длина типового ипотечного цикла в регионах (*норма отрасли* 30–60 дней). Пролонгация ≤15 дней — только если задержка не на стороне покупателя → нужна **ежедневная доска** статусов банк/документы.  
3. **Субсидия vs пресейл-диск:** клиент на субсидии может потерять ощущение «выгоды 228». Квалификация способа оплаты — **до** платной брони.  
4. **Invest/Dual (до ~40% матрицы):** чаще 100% / рассрочка / наличные; ипотека — сильнее у Local «жить». Микс оплаты меняет нагрузку на ипотечного брокера vs юр. сопровождение рассрочки.  
5. **Стресс-CR:** если доля ипотеки среди броней >60% без пула банков, ожидать CR бронь→ДДУ **45–55%** вместо 60% (*отрасль*) → нужно **58–70 броней** или усиление рассрочки.

### 4.3. Операционный чек-лист до брони

- [ ] Способ оплаты зафиксирован в договоре брони  
- [ ] При ипотеке: банк из пула, ПВ %, программа (субсид. / нет)  
- [ ] При рассрочке: график + надбавка ₽/м² озвучены письменно  
- [ ] Клиент понимает: отказ банка по согласованной программе → возврат; добровольный отказ → удержание расходов
