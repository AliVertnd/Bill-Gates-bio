# ЖК Талай — аналитика и линия IMPRO × Сибирь Девелопмент

Рабочее пространство для подготовки аналитики и коммерческих предложений по ЖК «Талай» (Горно-Алтайск).

## Для встречи с маркетинг-директором

| Документ | Назначение |
|---|---|
| **`docs/deliverables/10_презентация_md_8_13.md`** | Краткий deck **12 слайдов** (обсуждение, не продажа) |
| **`docs/deliverables/08_полный_документ_талай.md`** | Полный аналитический документ со всеми слоями |

## Структура

- `docs/sources/` — меморандумы, модель IMPRO (zip), GPT-справочно
- `docs/working/` — рабочие черновики анализа
- `docs/deliverables/` — материалы для встреч
- `data/` — таблицы hard data
