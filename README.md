# ЖК Талай — аналитика и линия IMPRO × Сибирь Девелопмент

Рабочее пространство для подготовки аналитики и коммерческих предложений по ЖК «Талай» (Горно-Алтайск) в логике модели IMPRO.

## Структура

- `docs/sources/` — исходники (меморандумы, выгрузки, внешние материалы)
- `docs/working/` — рабочие черновики анализа
- `docs/deliverables/` — финальные выжимки для встреч (маркетинг-директор → основатель)
- `data/` — таблицы и данные
